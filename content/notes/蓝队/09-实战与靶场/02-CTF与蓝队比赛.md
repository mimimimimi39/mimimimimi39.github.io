## 1. CTF 是什么

CTF（Capture The Flag）是信息安全竞赛，参赛者通过解题/攻防获取 flag。

常见方向：

| 方向 | 内容 | 对蓝队帮助 |
|---|---|---|
| Web | Web 漏洞利用 | 理解攻击与日志 |
| Misc | 杂项、编码、隐写 | 数据处理、取证 |
| Crypto | 密码学 | 密码学基础 |
| Reverse | 逆向 | 样本分析、恶意代码 |
| Pwn | 二进制漏洞 | 内存/漏洞原理 |
| Forensics | 取证 | 日志/流量/磁盘分析 |
| OSINT | 开源情报 | 情报收集 |

> 蓝队不必追求 Web/Pwn 拿分，重点在 Forensics、Misc、Crypto 与应急响应类比赛。

---

## 2. 蓝队相关比赛

| 比赛/类型 | 说明 |
|---|---|
| 应急响应赛 | 模拟入侵排查、日志分析、取证 |
| 数据分析赛 | 日志/流量分析、告警研判 |
| 溯源分析赛 | 攻击链还原、归因 |
| 护网/攻防演练 | 真实红蓝对抗 |
| CTF 取证题 | 磁盘/内存/流量取证 |
| Blue Team Village CTF | 蓝队专项 |
| CyberDefenders 挑战 | 蓝队练习 |
| SANS 类挑战 | 蓝队技能 |

国内赛事：

- 强网杯
- 网鼎杯
- 数字中国
- 护网行动（企业/单位组织）
- 各类行业赛

> 赛事信息以官方公告为准，注意报名资格与合规。

## 5. 比赛策略

1. 先做简单题，拿到基础分。
2. 分工明确，避免重复。
3. 记录尝试与线索。
4. 卡住及时换题。
5. 注意时间与体力。
6. 提交前检查格式。
7. 赛后复盘。

---

## 6. Writeup

```markdown
# 题目名称

## 题目描述
## 分析过程
## 关键步骤
## 答案
## 知识点
## 参考
```

> 比赛期间遵守规则，不泄露题目/答案，不攻击平台。

## 7. 对求职的帮助

- 证明学习能力与动手能力
- 面试可讲具体案例
- 团队协作
- 抗压能力
- 但：比赛成绩不等于工作能力，实习/项目更重要

---

## 8. 注意事项

- 只参加合法比赛
- 不攻击非授权目标
- 不传播恶意样本
- 不抄袭
- 保护个人信息
- 遵守平台规则
