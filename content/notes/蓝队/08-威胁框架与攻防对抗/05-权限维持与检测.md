## 1. 什么是权限维持

攻击者获得访问后，通过持久化机制确保**重启、改密、清理后仍能回来**。

蓝队目标：

- 知道常见持久化位置
- 能从日志/文件/注册表发现
- 能彻底清除
- 能补充检测

## 2. Windows 持久化

### 2.1 启动项

| 位置 | 说明 |
|---|---|
| `HKLM\Software\Microsoft\Windows\CurrentVersion\Run` | 全局 |
| `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` | 当前用户 |
| `RunOnce` | 仅一次 |
| `Wow6432Node` | 32 位兼容 |
| `Startup` 文件夹 | 用户/全局 |

检测：

- Sysmon 13（注册表值设置）
- Autoruns
- 文件创建（Startup 目录）

```powershell
Get-ItemProperty "HKLM:\Software\Microsoft\Windows\CurrentVersion\Run"
Get-ItemProperty "HKCU:\Software\Microsoft\Windows\CurrentVersion\Run"
```

### 2.2 服务

- 创建新服务
- 修改现有服务 `ImagePath`
- 服务 DLL
- 服务失败恢复

检测：

- 7045（System）
- 4697（Security）
- Sysmon 13（Services 注册表）
- 服务路径/签名/账号异常

### 2.3 计划任务

- 登录/启动/定时触发
- 执行脚本/程序
- 隐藏任务

检测：

- 4698 创建
- 4699 删除
- 4702 修改
- `C:\Windows\System32\Tasks`
- Sysmon 1（schtasks.exe）

### 2.4 WMI 事件订阅

- `__EventFilter`
- `CommandLineEventConsumer`
- `__FilterToConsumerBinding`

检测：

- Sysmon 19/20/21
- WMI-Activity 日志
- `wmiprvse.exe` 异常子进程

### 2.5 Winlogon

- `Shell`
- `Userinit`
- `Notify`

检测：Sysmon 13、注册表基线。

### 2.6 IFEO

Image File Execution Options 可劫持程序执行。

检测：注册表 `HKLM\Software\Microsoft\Windows NT\CurrentVersion\Image File Execution Options`。

### 2.7 AppInit_DLLs

- 加载到用户进程的 DLL
- 需 `LoadAppInit_DLLs=1`

检测：注册表、DLL 加载（Sysmon 7）。

### 2.8 COM 劫持

- 修改 CLSID 指向恶意 DLL
- 用户级/机器级

检测：注册表 `HKCU\Software\Classes\CLSID`、Sysmon 13。

### 2.9 DLL 劫持/侧加载

- 程序加载同目录恶意 DLL
- 搜索顺序劫持

检测：Sysmon 7、异常 DLL 路径/签名。

### 2.10 辅助功能后门

- `sethc.exe`、`utilman.exe`、`osk.exe`、`magnify.exe`
- 替换为 cmd.exe

检测：文件哈希/签名、文件修改、启动。

### 2.11 账号

- 创建后门账号
- 加入管理员组
- SID History
- 克隆账号
- 修改密码

检测：4720/4722/4724/4732/4738、SAM 变更。

### 2.12 域持久化

- Golden Ticket
- Silver Ticket
- DCSync 权限
- AdminSDHolder
- SID History
- 委派
- 域信任
- GPO 修改

检测：DC 日志、4662、4768/4769、权限变更。

### 2.13 其他

- BITS 任务
- Office 加载项
- 浏览器扩展
- 打印处理器
- Netsh helper DLL
- 时间提供程序
- SSP（Security Support Provider）
- 密码过滤器
- 启动驱动
- Webshell
- 计划任务 + WMI 组合

## 6. 清除原则

- 先取证，后清除
- 找到所有持久化，不要只删一个
- 修复入口
- 重置凭据
- 验证清除
- 持续监控
- 必要时重装

> 攻击者常设置多个持久化，删除一个就以为清理干净是常见错误。
