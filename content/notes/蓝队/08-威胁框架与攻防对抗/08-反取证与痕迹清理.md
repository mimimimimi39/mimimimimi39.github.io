## 1. 什么是反取证

攻击者为了隐藏行踪、破坏证据、延缓响应，采取的技术。

蓝队目标：

- 知道攻击者会清理什么
- 能发现清理行为
- 能从其他数据源恢复事实
- 保护日志与证据

---

## 2. 常见手法

### 2.1 日志清除

Windows：

```text
wevtutil cl Security
wevtutil cl System
Clear-EventLog -LogName Security
```

Linux：

```text
rm /var/log/auth.log
> /var/log/secure
history -c
```

检测：

- 1102（Security 清除）
- 104（System 清除）
- 日志时间缺口
- 日志服务停止
- 文件删除（auditd/FIM）
- 日志大小异常

### 2.2 时间戳篡改（Timestomping）

修改文件创建/修改时间，混淆时间线。

检测：

- Sysmon 2（文件创建时间修改）
- 时间戳与内容/其他痕迹矛盾
- `$STANDARD_INFORMATION` 与 `$FILE_NAME` 时间戳不一致
- 文件时间早于系统安装

### 2.3 文件删除/安全擦除

- 删除文件
- 覆盖/粉碎
- 清空回收站
- 删除卷影副本

检测：

- Sysmon 23/26
- USN Journal
- 文件系统日志
- 卷影副本删除事件
- 备份/快照

### 2.4 禁用审计/安全工具

- 停止日志服务
- 修改审核策略
- 关闭 EDR/AV
- 卸载 Agent
- 禁用防火墙

检测：

- 4719 审核策略变更
- 服务停止（7036/7040）
- EDR 篡改告警
- 注册表修改
- 防御规避技术（T1562）

### 2.5 Rootkit

- 内核模块
- 用户态 Hook
- 隐藏进程/文件/网络
- 引导工具

检测：

- 内核模块列表
- 内存取证
- 交叉视图（cross-view）
- 文件完整性
- EDR/反 Rootkit 工具

### 2.6 进程/服务隐藏

- 进程注入
- 服务伪装
- 计划任务隐藏
- WMI 持久化

检测：

- 多工具交叉验证
- 网络连接与进程不匹配
- 服务/任务对比
- 内存分析

### 2.7 其他

- 安全模式启动
- 修改系统时间
- 删除 Prefetch/Amcache
- 清除 USN Journal
- 使用内存/无文件
- 伪造日志
- 代理/跳板隐藏来源

## 3. 检测思路

| 手法 | 数据源 | 线索 |
|---|---|---|
| 日志清除 | 1102/104、日志缺口 | 清除事件、时间断档 |
| 时间戳 | Sysmon 2、MFT | 时间矛盾 |
| 文件删除 | Sysmon 23/26、USN | 删除记录 |
| 禁用审计 | 4719、服务日志 | 策略变更 |
| 关闭 EDR | EDR 告警、服务 | 服务停止/驱动卸载 |
| Rootkit | 内存、内核模块 | 隐藏对象、异常模块 |
| 安全模式 | 启动日志 | 异常启动 |
| 系统时间 | 时间服务日志 | 时间跳变 |

## 4. 对抗反取证

### 4.1 日志

- 集中日志（SIEM）
- 实时转发
- WORM/不可篡改存储
- 日志完整性校验
- 多副本
- 监控日志断流
- 监控清除事件

### 4.2 证据

- 内存优先
- 磁盘镜像
- 哈希
- 证据链
- 离线备份
- 快照

### 4.3 多源交叉

- 主机 + 网络 + 身份 + 应用 + 云
- 外部日志（防火墙、代理、DNS）
- EDR 遥测
- 蜜罐

### 4.4 检测

- 反取证行为规则
- 日志缺口告警
- 服务/驱动变更
- 时间异常
- Rootkit 扫描

---

## 5. 应急注意

- 不要只信主机日志
- 检查日志是否被清除
- 检查时间线是否被篡改
- 检查 EDR 是否被关闭
- 检查是否有多个持久化
- 保存内存与外部日志
- 必要时重装

---

## 6. 法律与道德

- 反取证技术仅用于防御研究与授权测试
- 不得帮助他人破坏证据
- 发现犯罪线索通过法务/执法处理
- 取证过程合法合规

---

## 7. 实操

1. 在实验机清除安全日志，观察 1102。
2. 修改文件时间戳，观察 Sysmon 2（需配置）。
3. 停止 Sysmon/日志服务，观察事件。
4. 检查日志缺口。
5. 用 Volatility 分析内存中的隐藏进程。
6. 用多源日志还原被清除的事件。
7. 写一条「日志清除」检测规则。

> 仅在自己的实验环境操作。
