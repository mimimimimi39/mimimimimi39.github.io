## 1. 入侵手法地图

```text
外部入口：钓鱼、弱口令、VPN/边缘设备、Web 漏洞、供应链、云配置
  → 执行：脚本、木马、Webshell
  → 持久化：服务、计划任务、启动项、账号
  → 提权：漏洞、配置、凭据
  → 凭据：LSASS、Kerberos、浏览器
  → 横向：RDP、SMB、WMI、WinRM、SSH
  → C2：HTTP/DNS/云服务
  → 外传/影响：数据、勒索、破坏
```

## 2. 弱口令与暴力破解

### 2.1 场景

- RDP/SSH/VPN/数据库/管理后台
- 默认口令
- 撞库
- 密码喷洒

### 2.2 检测

| 数据源 | 线索 |
|---|---|
| Windows 4625 | 大量失败、分散账号 |
| Linux auth.log | Failed password、Invalid user |
| VPN 日志 | 失败登录、异常地点 |
| 应用日志 | 登录失败、锁定 |
| WAF | 高频登录请求 |
| 情报 | 源 IP 恶意 |

**爆破成功特征**：失败后出现成功、成功来自新地点、成功后异常操作。

### 2.3 防御

- 强口令/MFA
- 账户锁定/限速
- 禁止公网暴露管理面
- 默认口令修改
- 凭据泄露监控

## 3. 钓鱼

### 3.1 场景

- 恶意附件（宏、LNK、ISO、HTML）
- 恶意链接
- 二维码
- 仿冒登录页
- BEC

### 3.2 检测

| 数据源 | 线索 |
|---|---|
| 邮件网关 | SPF/DKIM/DMARC 失败、异常发件人、附件 |
| 代理 | 新域名、仿冒域名、下载 |
| 终端 | Office → PowerShell、浏览器下载 |
| 账号 | 异常登录、MFA 变更 |
| 用户报告 | 最直接 |

### 3.3 防御

- 邮件过滤
- DMARC
- 沙箱
- 用户培训
- MFA
- 禁用宏
- 浏览器隔离

---

## 4. 公网应用漏洞

### 4.1 常见入口

- Web 漏洞（SQLi、上传、反序列化、SSRF）
- VPN/防火墙/邮件网关等边缘设备
- 中间件（Tomcat、WebLogic、Jenkins）
- 暴露的 API
- 管理后台

### 4.2 检测

- WAF 告警
- Web 日志异常请求
- 漏洞利用特征
- 异常子进程
- 文件落地
- 外连下载

### 4.3 防御

- 补丁
- 最小暴露
- WAF
- 代码安全
- 网络隔离
- 漏洞管理

---

## 5. 供应链

### 5.1 场景

- 软件更新被篡改
- 恶意依赖包
- 供应商账号被入侵
- 第三方组件漏洞
- 硬件/固件

### 5.2 检测

- 代码签名异常
- 依赖变更
- 异常更新
- 供应商访问日志
- 情报

### 5.3 防御

- 供应商评估
- SBOM
- 代码签名
- 依赖扫描
- 最小权限
- 隔离

> 供应链攻击隐蔽性强，检测难度高，重点在预防与快速情报响应。

## 6. 暴露的远程服务

### 6.1 RDP

- 公网暴露 + 弱口令
- 爆破
- 漏洞（BlueKeep 等）
- 凭据复用

**检测**：4625 类型 10、4624 类型 10、异常来源、RDP 爆破。

**防御**：VPN/堡垒机、MFA、限制来源、NLA、强口令。

### 6.2 SSH

- 爆破
- 密钥泄露
- 配置错误

**检测**：auth.log、异常登录、命令。

### 6.3 SMB

- 弱口令
- 永恒之蓝
- 横向

**检测**：445 连接、7045、5140。

### 6.4 数据库

- 公网暴露
- 弱口令
- 未授权

**检测**：数据库登录、异常查询、外连。

---

## 7. 云配置错误

- 对象存储公开
- 安全组 0.0.0.0/0
- IAM 过宽
- AccessKey 泄露
- 元数据服务被利用

**检测**：云审计、配置核查、密钥扫描、异常 API。

**防御**：最小权限、MFA、私有存储、IMDSv2、日志告警。

---

## 8. 内部威胁

- 合法权限滥用
- 数据带走
- 恶意内部人员
- 账号共享

**检测**：DLP、异常访问、非工作时段、批量下载、权限变更。

**防御**：最小权限、职责分离、审计、离职流程、培训。

---

## 9. 钓鱼后的常见行为链

```text
用户点击/打开附件
  → 执行脚本/宏
  → 下载载荷
  → 持久化
  → C2
  → 凭据窃取
  → 横向
  → 数据外传/勒索
```

检测重点：

- Office/浏览器子进程
- 下载
- 持久化
- 外联
- LSASS 访问
- 横向登录

## 10. 检测矩阵

| 入口 | 关键日志 | 关键事件 | 检测思路 |
|---|---|---|---|
| 弱口令 | 4625/4624、auth.log | 失败→成功 | 频率、来源、账号 |
| 钓鱼 | 邮件网关、代理、EDR | Office→PowerShell | 父子进程、下载 |
| Web 漏洞 | WAF、Web 日志、EDR | 异常请求、子进程 | 规则、行为 |
| VPN | VPN 日志 | 异常登录 | 地点、设备、时间 |
| 供应链 | 更新日志、签名 | 异常更新 | 签名、依赖 |
| 云 | 云审计 | IAM/存储变更 | 权限、API |
| 内部 | DLP、访问日志 | 批量下载 | 行为基线 |

---

## 11. 防御优先级

1. 减少暴露面（关闭公网管理面）
2. MFA
3. 补丁与漏洞管理
4. 最小权限
5. 日志与检测
6. 分段与隔离
7. 备份与恢复
8. 培训与演练

---

## 12. 实操

1. 在本地靶场模拟弱口令爆破，观察日志。
2. 模拟钓鱼附件执行，观察 Sysmon 父子进程。
3. 分析一次 Web 漏洞利用日志。
4. 检查实验环境的暴露端口。
5. 写一条「失败后成功」检测规则。
6. 做一次 ATT&CK 映射。
7. 复盘一个真实入侵报告。
