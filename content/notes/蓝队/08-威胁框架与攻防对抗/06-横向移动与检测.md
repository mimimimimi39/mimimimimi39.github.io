## 1. 什么是横向移动

攻击者从一台失陷主机移动到内网其他主机，扩大控制范围，最终接近核心资产（域控、数据库、数据）。

常见前提：

- 凭据（明文/哈希/票据）
- 远程服务
- 信任关系
- 共享
- 配置错误

## 2. 常见手法

| 手法 | 协议/端口 | 关键日志 |
|---|---|---|
| 口令复用 | 多种 | 4624、应用日志 |
| Pass-the-Hash | SMB/WMI 等 | 4624 类型 3、Sysmon |
| Pass-the-Ticket | Kerberos | 4768/4769 |
| NTLM Relay | SMB/HTTP | 4624、NTLM 日志 |
| RDP | 3389 | 4624 类型 10、4625 |
| SMB/共享 | 445 | 5140/5145 |
| PsExec | 445 | 7045、Sysmon 1 |
| WMI | 135/RPC | Sysmon 1、WMI 日志 |
| WinRM | 5985/5986 | PowerShell 日志、4624 |
| 计划任务 | RPC/SMB | 4698、Sysmon 1 |
| 远程服务 | RPC | 7045 |
| SSH | 22 | auth.log |
| VNC | 5900 | 登录日志 |
| 远程注册表 | 445 | 注册表访问 |

## 3. 关键日志与事件

### 3.1 Windows

| 事件 | 价值 |
|---|---|
| 4624 | 登录成功（类型 3 网络、10 RDP） |
| 4625 | 登录失败 |
| 4648 | 显式凭据 |
| 4672 | 特殊权限 |
| 4768/4769 | Kerberos |
| 4776 | NTLM |
| 5140/5145 | 共享访问 |
| 7045 | 服务安装（System） |
| 4698 | 计划任务 |
| 4688 | 进程创建 |
| Sysmon 1 | 进程/命令行 |
| Sysmon 3 | 网络连接 |
| Sysmon 17/18 | 命名管道 |

### 3.2 Linux

- auth.log/secure：SSH 登录
- auditd：execve、connect
- ~/.ssh/known_hosts：连接过的主机
- bash_history
- last/lastb

### 3.3 网络

- 445/135/3389/5985/22 连接
- 内网主机间异常连接
- 多主机同一来源
- 命名管道
- SMB 文件传输

## 4. 检测思路

### 4.1 登录异常

- 同一账号短时间登录多台主机
- 非工作时段
- 异常来源
- 失败后成功
- 类型 3/10 异常
- 管理员账号在普通工作站登录

### 4.2 服务/任务异常

- 7045 服务名随机（PSEXESVC 等）
- 服务路径 `ADMIN$`、`Temp`
- 4698 任务命令可疑
- 任务立即执行

### 4.3 进程异常

- `services.exe` → 异常子进程
- `wmiprvse.exe` → `cmd.exe`
- `wsmprovhost.exe` → PowerShell
- `psexesvc.exe`
- `cmd.exe` 网络连接

### 4.4 网络异常

- 内网 445 扫描
- 多主机 3389 连接
- 5985/5986
- 异常命名管道
- SMB 大文件传输

### 4.5 凭据异常

- LSASS 访问（Sysmon 10）
- 4769 RC4（Kerberoasting）
- 4768 无预认证
- NTLM 异常
- 4648 显式凭据

## 5. 示例查询

```spl
index=windows EventCode=4624 LogonType=3
| stats dc(ComputerName) as hosts count by AccountName, IpAddress
| where hosts > 5
| sort -hosts
```

```spl
index=windows EventCode=7045
| table _time ComputerName ServiceName ImagePath AccountName
| search ImagePath="*ADMIN$*" OR ImagePath="*Temp*" OR ServiceName="PSEXESVC"
```

```spl
index=sysmon EventCode=1
| search ParentImage="*wmiprvse.exe" OR ParentImage="*services.exe"
| table _time ComputerName User ParentImage Image CommandLine
```

## 6. 防御

### 6.1 身份

- 分层管理员（Tier 0/1/2）
- 域管只在 DC 使用
- LAPS
- MFA
- 最小权限
- 限制本地管理员
- 凭据保护（Credential Guard、LSA Protection）
- 禁用 NTLM（如可行）

### 6.2 网络

- 微分段
- 限制 445/135/3389/5985 横向
- 堡垒机
- VPN + MFA
- 出站限制
- 网络监控

### 6.3 主机

- 补丁
- EDR
- 应用白名单
- 禁用不必要服务
- 日志与 Sysmon
- 定期排查

### 6.4 监控

- 横向规则
- 异常登录
- 服务/任务
- 命名管道
- 内网流量

## 7. 应急排查

1. 确认失陷主机与账号。
2. 查看登录日志（4624 类型 3/10、4648）。
3. 查看服务/任务/进程（7045、4698、Sysmon 1）。
4. 查看网络连接（445/3389/5985）。
5. 查看凭据访问（Sysmon 10、4769）。
6. 确定横向范围（同账号、同网段、同漏洞）。
7. 隔离、重置凭据、清除持久化。
8. 全网排查。
9. 复盘与规则更新。

---

## 8. 实操

1. 在实验域环境用不同方式登录，观察 4624 类型。
2. 创建服务/计划任务，观察日志。
3. 分析一次 PsExec 行为的日志。
4. 写一条「同一账号登录多主机」规则。
5. 用 Wireshark 观察 SMB 横向流量。
6. 配置 LAPS/限制本地管理员（实验）。
7. 做一次横向移动排查演练。
