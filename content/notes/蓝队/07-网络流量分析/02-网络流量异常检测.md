## 1. 为什么要做流量异常检测

- 主机日志可能缺失/被清除。
- 加密流量下，内容看不到，但行为模式仍可见。
- 横向移动、C2、外传都会在网络留下痕迹。
- 流量基线能发现「正常中的异常」。

---

## 2. 数据源

| 数据源 | 粒度 | 用途 |
|---|---|---|
| 全流量 PCAP | 包级 | 深度分析、取证 |
| NetFlow/IPFIX | 会话级 | 流量统计、异常 |
| Zeek 日志 | 协议级 | 连接、DNS、HTTP、TLS |
| 防火墙日志 | 五元组 | 允许/拒绝、NAT |
| 代理日志 | 应用级 | URL、UA、上传下载 |
| DNS 日志 | 查询级 | 域名、隧道、DGA |
| IDS/NDR | 告警级 | 已知/行为检测 |
| 云流日志 | 会话级 | 云内/云间流量 |

## 3. 基线

### 3.1 建立基线

- 资产正常通信关系（谁访问谁）
- 正常端口/协议
- 正常流量大小/时间分布
- 正常 DNS/域名
- 正常外联目的地
- 正常用户行为

### 3.2 基线维度

- 按资产/网段
- 按业务
- 按时间（工作日/周末/白天/夜间）
- 按协议
- 按方向（入/出/内）
- 按频率/周期

> 没有基线，就难以判断「异常」。

---

## 4. 常见异常模式

### 4.1 扫描

- 大量 SYN 到多个端口/主机
- 短时间
- 少量完成连接
- ICMP/UDP 扫描
- 来源集中或分散

### 4.2 暴力破解

- 多次认证请求
- 固定间隔
- 失败为主
- 成功后行为变化

### 4.3 DDoS

- 流量突增
- 异常包类型（SYN Flood、UDP Flood、ICMP Flood）
- 源 IP 分散/伪造
- 带宽/连接数耗尽

### 4.4 C2 心跳

- 固定间隔（含抖动）
- 小包、低频
- 长连接/短连接
- 加密
- 异常域名/证书/JA3
- 非业务端口

### 4.5 DNS 隧道

- 长域名
- 高熵子域
- TXT/NULL/CNAME 异常
- 查询频率固定
- 响应数据量大
- 同一域名大量子域

### 4.6 数据外传

- 大流量上传
- 非工作时段
- 压缩/加密
- 分块
- 异常目的地/云存储
- 与下载不成比例

### 4.7 横向移动

- 内网 SMB/RDP/WinRM/SSH 连接
- 多主机同一来源
- 异常端口
- 服务创建
- 命名管道

### 4.8 隧道/代理

- DNS/ICMP/HTTP 隧道
- 非标准端口
- 协议伪装
- 长连接
- 代理链

### 4.9 ARP/DHCP 异常

- ARP 欺骗
- 流氓 DHCP
- IP 冲突
- MAC 变化

### 4.10 IPv6/加密绕过

- 只监控 IPv4，忽略 IPv6
- DoH/DoT 绕过 DNS 监控
- TLS 1.3/ECH 降低可见性

## 5. 检测方法

| 方法 | 说明 | 例子 |
|---|---|---|
| 阈值 | 超过阈值告警 | 单 IP 连接数 > N |
| 统计 | 均值/方差/分位数 | 流量突增 |
| 频率 | 单位时间次数 | 爆破、心跳 |
| 周期性 | 间隔方差小 | C2 beacon |
| 熵 | 域名/数据随机性 | DGA、隧道 |
| 协议 | 异常协议/端口 | 非标准端口 |
| 方向 | 上下行比例 | 外传 |
| 关系 | 通信图 | 横向 |
| 情报 | IOC 匹配 | 恶意 IP/域名 |
| 指纹 | JA3/JA3S（被动）、JARM（主动探测） | C2 |
| 机器学习 | 异常检测 | UEBA/NDR |

## 6. Zeek 日志

| 日志 | 内容 |
|---|---|
| `conn.log` | 连接五元组、时长、字节 |
| `dns.log` | DNS 查询/响应 |
| `http.log` | HTTP 请求 |
| `ssl.log` | TLS 握手、证书、SNI |
| `files.log` | 文件传输 |
| `notice.log` | 告警 |
| `weird.log` | 异常 |
| `x509.log` | 证书 |

分析示例：

```bash
# 连接最多的目的 IP
cat conn.log | zeek-cut id.resp_h | sort | uniq -c | sort -nr | head

# 长 DNS 查询
cat dns.log | zeek-cut query | awk 'length($0)>100' | head

# 自签名证书
cat x509.log | zeek-cut certificate.subject certificate.issuer
```

## 7. C2 检测

### 7.1 心跳分析

- 同一 src/dst 多次连接
- 间隔稳定（方差小）
- 持续时间长
- 数据量小
- 周期可含抖动

### 7.2 指纹

- JA3/JA3S
- 证书（自签名、异常主题、短期）
- SNI
- User-Agent
- URI 模式

### 7.3 行为

- 非业务进程外联
- 非工作时段
- 异常端口
- 多级域名
- 动态解析（DGA/fast flux）

### 7.4 工具

- RITA（C2 分析，维护状态需确认）
- Zeek
- Arkime
- Suricata
- JA3
- JARM

---

## 8. 检测流程

```text
1. 明确假设（扫描/C2/外传/横向）
2. 选择数据源与时间范围
3. 建立/对比基线
4. 过滤与聚合
5. 关联主机/身份/情报
6. 验证误报
7. 形成结论与规则
```

---

## 9. 实操

1. 用 Zeek 处理一份 PCAP，分析 conn/dns/http/ssl。
2. 统计 Top 目的 IP/域名。
3. 找长域名与高熵域名。
4. 分析一个 C2 样本的心跳间隔。
5. 用 Wireshark 分析扫描与爆破。
6. 建立一个小型网络的流量基线。
7. 写一条 Suricata/Zeek 检测规则。

---

## 10. 常见误区

- 没有基线，凭感觉判断
- 只看流量大小，不看行为
- 忽略内网横向
- 忽略加密流量元数据
- 不做多源关联
- 误把 CDN/云服务当恶意
- 忽略 IPv6/DoH
- 只看告警不看原始数据
