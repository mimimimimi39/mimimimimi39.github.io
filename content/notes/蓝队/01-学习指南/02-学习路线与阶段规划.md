## 1. 学习原则

1. **目标导向**：以「能实习」为目标，不以「学完所有安全知识」为目标。
2. **实验优先**：每个知识点都要落到「看得见的日志/流量/工具操作」。
3. **输出倒逼**：每篇笔记必须包含原理、检测、防御、案例。
4. **螺旋上升**：先广度建立地图，再深度攻克高频领域，最后回到广度串联。
5. **持续复盘**：每周回顾一次「学到了什么、还缺什么、下周做什么」。

## 2. 阶段拆解

### 阶段 0：认知与准备（1-2 周）

| 任务 | 产出 |
|---|---|
| 了解蓝队岗位与能力模型 | 岗位笔记 |
| 制定学习计划 | 周计划表 |
| 搭建虚拟机与工具环境 | 可用实验环境 |
| 了解法律与授权边界 | 合规笔记 |

**验收**：能说清自己为什么学蓝队、目标岗位是什么、每周能投入多少小时。

### 阶段 1：计算机与网络基础（6-8 周）

| 模块 | 重点 | 实验 |
|---|---|---|
| 计算机组成 | CPU/内存/磁盘、进程线程、文件系统 | 用任务管理器/ps 观察进程 |
| Linux | 命令、权限、服务、日志、SSH、cron | OverTheWire Bandit、日志排查 |
| Windows | 账号、注册表、服务、域、事件查看器 | 查找启动项、计划任务、登录日志 |
| 网络 | OSI/TCP-IP、TCP/UDP、IP、端口、协议 | Wireshark 抓包、ping/traceroute/nslookup |
| HTTP/TLS/DNS | 报文、状态码、握手、解析 | 浏览器 F12 + Wireshark |
| 数据库 | 表、SQL、事务、日志 | 安装 MySQL，建库建表查询 |

**验收**：能完整解释「浏览器访问 https://example.com 发生了什么」。

### 阶段 2：编程与数据处理（4-5 周）

| 模块 | 学到什么程度 | 实验 |
|---|---|---|
| Python | 能读写文件、发请求、处理 JSON、写函数 | 日志统计、IOC 提取、VT 查询 |
| PowerShell | 能查进程/服务/日志/计划任务 | 写一个主机排查脚本 |
| Bash | 能管道处理日志 | Top IP、爆破统计 |
| SQL | 能 SELECT/JOIN/GROUP BY | 查询登录日志表 |
| 正则 | 能写常见 IOC 正则 | regex101 练习 |

**验收**：能独立写脚本完成「读取日志 → 提取字段 → 统计 → 输出报告」。

### 阶段 3：安全基础与攻击框架（5-6 周）

| 模块 | 重点 |
|---|---|
| 安全概念 | CIA、AAA、纵深防御、零信任、合规 |
| 密码学 | 对称/非对称、哈希、签名、证书、编码 |
| 攻击总览 | Web、主机、网络、社工、供应链 |
| 漏洞管理 | CVE、CVSS、CWE、EPSS、KEV、补丁 |
| Web 漏洞 | OWASP Top 10、SQLi、XSS、CSRF、上传、命令注入、SSRF、XXE、反序列化 |
| Webshell | 类型、特征、检测、处置 |
| 云安全 | 责任共担、IAM、对象存储、云日志 |
| ATT&CK/Kill Chain | 14 个战术、七阶段、与检测映射的关系（先建立地图，阶段 6 深入） |

**验收**：能对每个漏洞说出「原理 → 日志/流量特征 → 检测方法 → 防御措施」，能说出 ATT&CK 战术与 Kill Chain 阶段。

### 阶段 4：主机与流量分析（8-10 周）

| 模块 | 重点 |
|---|---|
| 日志源 | 主机、网络、安全设备、应用、云日志与规范化 |
| Windows 安全机制 | 令牌、UAC、ACL、审核、AD |
| Windows 日志 | 关键事件 ID、登录类型、日志清除 |
| Sysmon | 事件 ID、配置、检测用例 |
| Linux 审计 | auth.log、journald、auditd |
| EDR/HIDS | 原理、告警、处置 |
| 恶意软件 | 类型、家族、C2、处置 |
| 样本分析 | 静态/动态、沙箱、YARA |
| 流量分析 | Wireshark、异常检测、NIDS |

**验收**：能列出主要日志源并说明关键字段，能从主机日志还原攻击链，能从 PCAP 找出恶意流量。

### 阶段 5：蓝队核心能力（6-7 周）

| 模块 | 重点 |
|---|---|
| SOC | L1/L2/L3、流程、指标、工单 |
| SIEM | 采集、解析、关联、查询、调优 |
| 告警研判 | 五要素、上下文、误报、定性定级 |
| IR | NIST/SANS 流程、团队、沟通、证据 |
| 应急实战 | 挖矿、勒索、Webshell、钓鱼、数据泄露 |
| 威胁情报 | IOC/IOA/TTP、金字塔、平台 |
| 威胁狩猎 | 假设驱动、TaHiTI/PEAK、案例 |
| 溯源取证 | 主机/内存/网络、时间线、证据链 |

**验收**：能独立完成一次告警研判和一次模拟应急，并写出报告。

### 阶段 6：攻防对抗与实战（8-10 周）

| 模块 | 重点 |
|---|---|
| ATT&CK | 技术/子技术、检测映射、覆盖评估（在阶段 3 概览基础上深入） |
| Kill Chain | 复习七阶段、与 ATT&CK 对比 |
| 红蓝对抗 | 演练组织、红队手法、蓝队防守 |
| 入侵手法 | 弱口令、漏洞、钓鱼、供应链、云配置 |
| 权限维持 | 启动项、服务、计划任务、WMI、SSH |
| 横向移动 | PTH/PTT、RDP、SMB、WMI、WinRM |
| 内存马/无文件 | 类型、检测 |
| 反取证 | 日志清除、时间戳、Rootkit |
| 靶场/项目 | 10+ 蓝队靶场、1 个综合项目 |

**验收**：能把案例映射到 ATT&CK，写出检测思路，完成项目展示。

### 阶段 7：求职冲刺（2-3 周）

| 任务 | 产出 |
|---|---|
| 简历 | 一页 PDF |
| 项目集 | GitHub/博客 |
| 面试题库 | 高频题答案 |
| 模拟面试 | 3 次以上 |
| 投递与复盘 | 投递记录、失败原因分析 |

**验收**：能流畅介绍自己、项目、一次完整分析过程。

## 3. 时间预算

| 节奏 | 每周投入 | 总周期 | 适合人群 |
|---|---|---|---|
| 稳健 | 10-15 小时 | 11-17 个月 | 在校、在职 |
| 标准 | 15-20 小时 | 9-12 个月 | 在校高年级、待业 |
| 加速 | 30-35 小时 | 5-6 个月 | 全职学习、培训班 |
| 极限 | 40+ 小时 | 4-5 个月 | 有 IT 基础、强执行力 |

> 不要迷信「3 个月速成」。如果目标是能独立值班和做基础应急，600-800 小时是比较现实的投入；每周投入越少，周期越长。

## 4. 每周学习模板

```text
周一至周五（每天 2 小时）
  1 小时：看文档/视频，做笔记
  1 小时：动手实验/做题

周六（4-6 小时）
  2 小时：完成本周实验
  2 小时：写本周总结（原理 + 日志特征 + 检测 + 疑问）
  1 小时：复盘错题与盲区

周日（2 小时）
  预习下周内容
  更新学习计划与项目进度
```

### 笔记模板

```markdown
# 主题

## 一句话解释
## 核心原理
## 关键概念/命令/事件 ID
## 日志与流量特征
## 检测方法
## 防御与加固
## 实验记录
## 疑问与待办
## 参考资料
```

## 5. 输出物清单

建议在 GitHub 建立一个 `blue-team-notes` 仓库：

```text
blue-team-notes/
├── 01-basics/           基础笔记
├── 02-security/         安全基础
├── 03-soc/              SOC 与日志
├── 04-ir/               应急响应案例
├── 05-traffic/          流量分析报告
├── 06-malware/          样本分析报告
├── 07-labs/             靶场 Writeup
├── 08-projects/         综合项目
└── README.md            个人学习路线与索引
```

每个实验至少包含：

1. 背景与目标
2. 环境与数据
3. 分析过程（命令、截图、日志）
4. 结论与时间线
5. 检测规则/改进建议
6. 复盘（哪里卡住、下次怎么优化）

## 6. 常见问题

### Q1：先学 Linux 还是 Windows？

看目标岗位。甲方 Windows 环境多，先 Windows 日志与 AD 基础；安全厂商/互联网 Linux 多，先 Linux。建议两个都学，先学你更陌生的那个。

### Q2：要不要学渗透测试？

要理解原理，但不需要成为渗透工程师。蓝队学习攻击是为了设计检测。建议掌握常见 Web 漏洞、弱口令、权限维持、横向移动的基本概念与日志特征。

### Q3：编程要学到什么程度？

能写 100-300 行脚本解决问题即可。重点：文件处理、HTTP 请求、JSON/CSV、正则、异常处理、调用 API。不需要刷算法题。

### Q4：要不要考证？

证书是加分项，不是入场券。应届生优先项目与实习；转行优先基础与项目。具体见 [认证与职业发展](04-认证与职业发展.md)。

### Q5：英语不好怎么办？

蓝队一手资料大量是英文。每天读 15 分钟官方文档，先看 ATT&CK、Microsoft Learn、SANS 博客，坚持 3 个月会有明显提升。

### Q6：学完就能找到工作吗？

不一定。还需要：简历、项目、面试表达、投递策略、城市与岗位匹配。技术只是其中一部分。

## 7. 避坑清单

- 不要收藏 100 个工具却不用。
- 不要只看视频不做实验。
- 不要一开始就啃内核/逆向/高级免杀。
- 不要忽视日志与文档能力。
- 不要在没有授权的情况下测试任何真实系统。
- 不要简历造假，面试官追问会露馅。
- 不要孤军奋战，加入社区、找学习搭子、参加比赛。
