## 1. 为什么先学这一篇

很多初学者一上来就学工具、背命令，学了半年仍然不知道自己「能做什么岗位、面试考什么、每天干什么」。先把岗位地图看清楚，后面的学习才有目标。

本篇解决三个问题：

1. 蓝队到底有哪些岗位？
2. 每个岗位每天做什么、需要什么能力？
3. 零基础应该瞄准哪个入口岗位，如何往上走？

---

## 2. 蓝队、红队与紫队

| 角色 | 目标 | 典型工作 | 产出 |
|---|---|---|---|
| 红队（Red Team） | 模拟真实攻击，检验防御 | 情报收集、外网打点、钓鱼、内网渗透、C2 | 攻击报告、风险证明 |
| 蓝队（Blue Team） | 防御、检测、响应、恢复 | 监控告警、日志分析、应急响应、基线加固 | 告警工单、事件报告、加固方案 |
| 紫队（Purple Team） | 促进红蓝协作，提升检测覆盖 | 攻击模拟、检测映射、规则验证 | ATT&CK 覆盖报告、检测规则 |

> 蓝队的核心不是「会多少黑客工具」，而是**能否在大量数据中发现问题、判断问题、处理问题，并让同类问题不再发生**。

## 3. 蓝队岗位分类

### 3.1 SOC 分析师（安全运营中心）

| 级别 | 职责 | 能力要求 |
|---|---|---|
| L1 | 7×24 监控告警、初步分类、工单记录、按手册升级 | 会看告警、懂基础网络与系统、会写工单 |
| L2 | 深入研判、关联多源日志、判断事件等级、提出处置建议 | 熟悉日志与 ATT&CK、会流量分析、能独立定性 |
| L3 | 复杂事件处置、威胁狩猎、检测规则开发、带教 | 精通应急、取证、检测工程、脚本开发 |

**日常关键词**：值班、告警队列、误报、工单、SLA、升级、交接班、日报周报。

### 3.2 应急响应工程师（IR）

处理已确认或疑似安全事件：入侵排查、勒索/挖矿处置、Webshell 清理、数据泄露调查、取证与报告。

**能力要求**：Windows/Linux 深度排查、日志与流量、恶意样本、取证工具、沟通与文档、抗压能力。

### 3.3 安全运营工程师（Security Operations）

负责 SIEM/EDR/态势感知平台的运营：日志接入、解析、关联规则、告警调优、SOAR 自动化、指标建设。

**能力要求**：SIEM 查询、正则、脚本、日志规范化、检测工程、平台运维。

### 3.4 威胁情报分析师（CTI）

生产与消费情报：IOC 收集与验证、TTP 分析、事件归因、情报落地到检测规则。

**能力要求**：开源情报、英文阅读、恶意样本基础、ATT&CK、STIX/TAXII、MISP。

### 3.5 威胁狩猎工程师（Threat Hunting）

不等告警，主动假设「攻击者可能已经进来」，用数据验证假设，产出新检测规则。

**能力要求**：ATT&CK、日志与流量、统计分析、假设设计、检测工程。

### 3.6 安全服务/驻场工程师

做基线核查、漏洞扫描、风险评估、等保测评配合、客户应急支持。是很多新人进入安全行业的入口。

**能力要求**：等保标准、加固基线、扫描工具、报告写作、客户沟通。

### 3.7 安全研发/检测工程师

开发检测平台、EDR/SIEM 规则、自动化工具、数据管道。偏工程。

**能力要求**：Python/Go/Java、后端、大数据、安全知识、工程能力。

## 4. 一天的工作长什么样

以 SOC L1 为例：

| 时间 | 工作 |
|---|---|
| 08:50 | 交接班，查看未闭环工单与重点资产 |
| 09:00 | 处理夜间积压告警，按优先级初判 |
| 10:30 | 对可疑登录/恶意 IP 告警做多源关联 |
| 12:00 | 记录工单，升级无法定性的事件 |
| 14:00 | 配合 L2 做主机排查、封禁 IP、联系业务确认 |
| 16:00 | 更新值班日志，整理误报原因 |
| 17:30 | 交接未完成事项 |

以 IR 为例：

| 阶段 | 工作 |
|---|---|
| 接警 | 确认事件真实性、影响范围、是否仍在扩散 |
| 遏制 | 隔离主机、禁用账号、封禁 IP、备份证据 |
| 排查 | 进程、网络、账号、计划任务、日志、样本 |
| 清除 | 删除恶意文件、修复入口、重置凭据 |
| 恢复 | 验证业务、持续监控 |
| 复盘 | 时间线、根因、改进项、报告 |

## 5. 能力模型

### 5.1 技术能力

```text
网络与协议
  └─ TCP/IP、HTTP、DNS、TLS、SMB、Kerberos、LDAP
操作系统
  └─ Linux 命令与日志、Windows 账号/服务/注册表/事件日志
编程与数据
  └─ Python、PowerShell、Bash、SQL、正则
安全基础
  └─ 漏洞原理、密码学、Web 安全、恶意代码
检测与响应
  └─ SIEM、EDR、NIDS、日志分析、流量分析、取证
威胁框架
  └─ ATT&CK、Kill Chain、威胁情报
```

### 5.2 流程能力

- 事件分级与升级流程
- 工单与交接班规范
- 证据保全与链条
- 变更管理与配置基线
- 演练与复盘机制

### 5.3 软技能

- **写作**：工单、报告、复盘要能让非技术人员看懂。
- **沟通**：向业务确认、向领导汇报、向厂商求助。
- **抗压**：真实事件中信息不全、时间紧迫。
- **好奇心**：持续追问「为什么」。

### 5.4 法律与合规

- 只做授权范围内的操作
- 保护个人信息与企业秘密
- 证据采集合法合规
- 了解《网络安全法》《数据安全法》《个人信息保护法》与等保 2.0

## 6. 成长路径

```text
安全服务/驻场 → SOC L1 → SOC L2 → IR / 威胁狩猎 / 检测工程 → 安全专家 / 安全经理
                     ↘ 威胁情报
                     ↘ 安全研发
```

常见转行入口：

| 背景 | 优势 | 建议入口 |
|---|---|---|
| 网络工程师 | 协议与设备熟悉 | SOC、安全服务 |
| 系统运维 | Linux/Windows 熟练 | SOC、IR |
| 开发 | 编程强 | 安全研发、检测工程 |
| 应届生 | 可塑性强、时间多 | 实习、SOC L1 |
| 其他行业 | 沟通与行业知识 | 安全服务、合规 |

## 7. 面试官在看什么

初级蓝队面试通常考察：

1. **基础是否扎实**：TCP 三次握手、HTTP 状态码、Linux 命令、Windows 事件 ID。
2. **是否真的做过**：让你讲一次告警研判或应急经历。
3. **分析思路**：给一个场景，看你怎么一步步排查。
4. **工具熟练度**：Wireshark、Sysmon、SIEM 查询、VT。
5. **文档与表达**：能否把问题讲清楚。
6. **学习能力与态度**：遇到不会的怎么补。
7. **法律意识**：是否知道授权边界。

> 没有真实工作经验时，用**靶场案例 + 个人项目 + 详细报告**替代。面试官更看重你「怎么想」，而不是「做过多少年」。
