## 一、网络基础

### 1. TCP 三次握手与四次挥手？【高频】

**要点**：

- 三次握手：SYN → SYN+ACK → ACK，确认双方收发能力。
- 四次挥手：FIN → ACK → FIN → ACK，双方独立关闭。
- 半连接、TIME_WAIT、RST 的含义。
- 安全场景：SYN Flood、端口扫描、异常 RST。

### 2. TCP 与 UDP 的区别？【高频】

**要点**：

- TCP 面向连接、可靠、有序、有流量控制；UDP 无连接、不可靠、开销小。
- TCP：HTTP/1.1、SSH、SMB、RDP；UDP：DNS、DHCP、NTP、QUIC、VoIP。
- 安全：UDP 可用于放大攻击、隧道；TCP 扫描更常见。

### 3. 常见端口及对应服务？

**要点**：

- 22 SSH、23 Telnet、25 SMTP、53 DNS、80 HTTP、443 HTTPS、445 SMB、1433 MSSQL、3306 MySQL、3389 RDP、6379 Redis、9200 Elasticsearch、27017 MongoDB。
- 端口可改，判断服务要看协议特征。

### 4. 常见 HTTP 状态码及安全含义？

**要点**：

- 200 成功、301/302 重定向、304 未修改、400 请求错误、401 未认证、403 禁止、404 不存在、405 方法不允许、429 限流、500 服务器错误、502/504 网关问题。
- 大量 404/403 → 扫描；500 → 注入/异常；200 但异常 → Webshell。

### 5. HTTPS 握手与证书？【高频】

**要点**：

- TLS 1.2 约 2-RTT，TLS 1.3 约 1-RTT。
- ClientHello（SNI、套件）→ ServerHello、证书 → 密钥交换 → Finished。
- 证书验证：签名链、域名/SAN、有效期、吊销、用途。
- 前向保密（ECDHE）。
- 检测：证书异常、SNI、JA3/JA3S。

### 6. DNS 解析过程？

**要点**：

- 本地缓存 → 递归解析器 → 根 → TLD → 权威服务器。
- 记录：A、AAAA、CNAME、MX、TXT、NS、PTR、SRV、CAA。
- 安全：DNS 隧道、DGA、劫持、缓存投毒、DoH/DoT。

### 7. NAT 是什么？对溯源有什么影响？

**要点**：

- 私有 IP 与公网 IP 转换；SNAT/DNAT。
- 日志中看到的是 NAT 后地址，需结合 NAT 表/时间戳溯源。
- 共享 IP 可能导致误封。

### 8. 从输入 URL 到页面展示发生了什么？【高频】

**要点**：

- 浏览器解析 URL → DNS → TCP 握手 → TLS 握手 → HTTP 请求 → 服务器处理 → 响应 → 渲染。
- 中间涉及代理、CDN、WAF、负载均衡。
- 安全关注：DNS 劫持、证书、重定向、注入。

### 9. 如何判断 DDoS？

**要点**：

- 流量突增、带宽/连接数耗尽、服务不可用。
- 类型：SYN Flood、UDP Flood、ICMP Flood、HTTP Flood、反射放大。
- 看 NetFlow、防火墙、负载均衡、应用日志。
- 处置：清洗、限流、封禁、CDN/高防。

### 10. X-Forwarded-For 为什么不能直接信任？

**要点**：

- 客户端可伪造。
- 应用应只信任可信代理设置的头部。
- 日志污染、IP 封禁绕过、越权风险。
- 结合代理链与真实来源判断。

## 二、操作系统

### 11. Linux 如何查看进程、端口、连接？【高频】

**要点**：

- 进程：`ps aux`、`ps -ef --forest`、`top`、`/proc/<pid>`。
- 端口：`ss -tulnp`、`netstat -antp`、`lsof -i`。
- 连接：`ss -antp state established`。
- 可疑：路径在 /tmp、/dev/shm，删除后仍运行，异常父进程。

### 12. Linux 权限模型？

**要点**：

- rwx、属主/组/其他、数字权限。
- 特殊权限：SUID、SGID、Sticky。
- `chmod`、`chown`、`umask`。
- 提权风险：SUID、sudo、capabilities、可写服务。

### 13. Linux 常见日志及用途？

**要点**：

- auth.log/secure：登录、SSH、sudo。
- syslog/messages：系统。
- auditd：审计。
- journald：systemd。
- wtmp/btmp：登录成功/失败。
- Web 日志：访问/错误。

### 14. Linux 常见持久化位置？【高频】

**要点**：

- cron、systemd 服务/定时器、rc.local、profile/bashrc。
- SSH authorized_keys、sudoers、UID 0 账号。
- SUID、ld.so.preload、内核模块。
- Web 目录 Webshell。
- 检测：文件完整性、auditd、日志、异常进程。

### 15. Windows 关键事件 ID？【高频】

**要点**：

- 4624 登录成功、4625 失败、4648 显式凭据、4672 特殊权限。
- 4688 进程创建、4698 计划任务、7045 服务安装。
- 4720 创建用户、4732 加入本地管理员组。
- 4768/4769 Kerberos、4776 NTLM。
- 1102 安全日志清除、4104 PowerShell 脚本块。

### 16. 4624 登录类型 2/3/10 的区别？【高频】

**要点**：

- 2 交互式本地登录。
- 3 网络登录（共享、远程）。
- 10 远程桌面。
- 其他：4 批处理、5 服务、7 解锁、8 网络明文、9 新凭据、11 缓存。
- 横向移动常看 3/10。

### 17. Windows 如何排查启动项？

**要点**：

- Run/RunOnce（HKLM/HKCU、Wow6432Node）。
- Startup 文件夹。
- 服务、计划任务、WMI 订阅。
- Winlogon、IFEO、AppInit_DLLs、COM。
- Autoruns 全量；Sysmon 13。

### 18. Windows 服务排查看什么？

**要点**：

- 服务名、显示名、路径、运行账号、启动类型。
- 路径是否在 Temp/Public/ProgramData。
- 签名、哈希、创建时间。
- 7045/4697、Sysmon 13。
- 异常服务可能是持久化/提权。

### 19. Sysmon 常用事件 ID？【高频】

**要点**：

- 1 进程创建、3 网络连接、7 镜像加载、8 远程线程、10 进程访问。
- 11 文件创建、12/13/14 注册表、15 ADS。
- 17/18 命名管道、19/20/21 WMI、22 DNS、25 进程篡改。
- 结合命令行、父进程、哈希分析。

### 20. Linux 提权如何排查？

**要点**：

- UID 0 账号、空密码、sudoers。
- SUID/SGID、capabilities。
- 可写服务/配置、cron。
- 内核漏洞、脏牛等。
- 检测：auditd、文件完整性、异常命令。

## 三、安全基础与 Web

### 21. CIA 三元组？【高频】

**要点**：

- 机密性、完整性、可用性。
- 扩展：真实性、不可否认性、可追溯性。
- 举例：数据泄露、篡改、DDoS。

### 22. 哈希、加密、编码的区别？【高频】

**要点**：

- 编码：格式转换，可逆无密钥（Base64）。
- 加密：可逆，有密钥（AES/RSA）。
- 哈希：不可逆（SHA-256），用于完整性/密码。
- 密码存储用 bcrypt/Argon2id + 盐。

### 23. OWASP Top 10 2021？【高频】

**要点**：

- A01 访问控制失效、A02 加密失效、A03 注入、A04 不安全设计、A05 安全配置错误。
- A06 过时组件、A07 认证失败、A08 完整性失效、A09 日志监控失效、A10 SSRF。
- 蓝队重点关注 A01/A03/A09/A10。

### 24. SQL 注入原理与防御？【高频】

**要点**：

- 用户输入拼接 SQL，改变语义。
- 类型：联合、布尔盲注、时间盲注、报错、堆叠、二次、OOB。
- 防御：参数化查询、最小权限、输入校验、WAF（补充）。
- 检测：Web 日志关键字、500、响应时间、WAF。

### 25. XSS 类型与防御？

**要点**：

- 反射、存储、DOM。
- 危害：窃取会话、钓鱼、蠕虫。
- 防御：输出编码（按上下文）、CSP、HttpOnly、输入校验。
- 检测：参数含脚本、CSP 报告、异常回显。

### 26. CSRF 原理与防御？

**要点**：

- 利用已登录用户的 Cookie 发起请求。
- 条件：已登录、Cookie 认证、参数可预测、无 Token。
- 防御：CSRF Token、SameSite、Origin/Referer 校验、二次确认。
- 检测：异常 Referer/Origin、敏感操作。

### 27. 文件上传漏洞如何防御？

**要点**：

- 扩展名白名单、MIME/内容校验、重命名。
- 存储到 Web 根目录外、上传目录禁止执行。
- 限制大小、AV/YARA、最小权限。
- 检测：上传日志、新文件、Web 进程子进程。

### 28. 命令注入原理与防御？

**要点**：

- 用户输入拼接系统命令。
- 拼接符：`;`、`|`、`&&`、`||`、`$()`、反引号。
- 防御：避免 shell、参数化/白名单、最小权限、容器隔离。
- 检测：Web 日志特殊字符、Web 进程拉起 shell。

### 29. SSRF 原理与防御？【高频】

**要点**：

- 服务端请求用户指定 URL，访问内网/元数据。
- 目标：127.0.0.1、内网、169.254.169.254。
- 协议：http、file、gopher、dict。
- 防御：白名单、解析后校验 IP、禁协议、网络隔离、IMDSv2。

### 30. XXE 原理与防御？

**要点**：

- XML 外部实体读取文件/SSRF/DoS。
- 入口：SOAP、XML API、SVG、Office。
- 防御：禁用 DTD/外部实体、安全解析器、限制大小。
- 检测：请求含 DOCTYPE/ENTITY、异常外连。

### 31. 反序列化漏洞原理？

**要点**：

- 不可信数据反序列化触发 gadget 链。
- Java：ObjectInputStream、Fastjson、Shiro、Jackson。
- PHP：unserialize；.NET：BinaryFormatter；Python：pickle。
- 防御：避免反序列化不可信数据、白名单、升级组件、禁用危险功能。

### 32. Webshell 如何检测？

**要点**：

- 文件：新增脚本、危险函数、混淆、时间异常。
- 日志：POST 到脚本、异常参数/UA、上传后访问。
- 主机：Web 进程子进程、外连、文件落地。
- 工具：YARA、D盾、河马、EDR。
- 处置：隔离、取证、清除、修复入口。

### 33. CVE、CVSS、CWE 的区别？【高频】

**要点**：

- CVE：具体漏洞编号。
- CWE：漏洞类型/弱点分类。
- CVSS：严重性评分（0-10）。
- 补充：EPSS 利用概率、KEV 已知被利用。

### 34. 0day 与 Nday 的区别？

**要点**：

- 0day：厂商无补丁/未公开。
- Nday：已有补丁但未修复。
- 0day 检测难，靠行为/情报；Nday 靠补丁管理。

### 35. WAF 能防所有 Web 攻击吗？

**要点**：

- 不能。WAF 是纵深防御一层。
- 可能被编码/分块/协议差异绕过。
- 需要安全开发、补丁、代码审计、RASP。
- WAF 误报需调优。

## 四、日志与检测

### 36. 如何发现暴力破解？【高频】

**要点**：

- 4625/auth.log 失败次数、频率、源 IP。
- 失败后成功、异常地点/时间。
- 账号分散（密码喷洒）vs 单账号（爆破）。
- 处置：封禁、锁定、MFA、改密、排查主机。

### 37. 如何发现 Webshell？【高频】

**要点**：

- Web 目录新增/修改脚本。
- POST 到脚本、异常参数/UA、响应短。
- Web 进程拉起 cmd/powershell/sh。
- 文件完整性/YARA/EDR。
- 关联上传日志与入口。

### 38. 如何发现 C2？【高频】

**要点**：

- 固定心跳、小包、加密、异常域名/证书。
- 进程外连、非业务端口。
- JA3/JA3S、DNS、代理日志。
- 情报匹配、威胁狩猎。
- 结合主机进程与持久化。

### 39. 如何发现横向移动？

**要点**：

- 4624 类型 3/10、4648、4672。
- 7045 服务、4698 任务、5140 共享。
- 同一账号多主机、异常来源。
- SMB/RDP/WinRM 流量、命名管道。
- LSASS 访问、Kerberos 异常。

### 40. 如何发现挖矿？

**要点**：

- CPU/GPU 高、异常进程、矿池域名/IP。
- 计划任务/服务持久化。
- 云上异常计费。
- 处置：隔离、清除、修复入口、重置凭据。

### 41. 如何发现勒索？

**要点**：

- 大量文件加密/重命名、勒索说明。
- 卷影副本删除、备份服务停止。
- 异常 SMB/RDP 横向。
- 处置：隔离、断网、保存证据、检查备份、不支付、上报。

### 42. 如何发现日志清除？

**要点**：

- 1102/104。
- 日志时间缺口、文件删除。
- 日志服务停止、审核策略变更（4719）。
- 多源对比（SIEM/外部日志）。
- 高优先级信号。

### 43. 如何发现权限维持？

**要点**：

- 服务（7045）、计划任务（4698）、启动项（Sysmon 13）。
- WMI 订阅（19/20/21）、账号（4720/4732）。
- Linux cron/systemd/SSH key。
- 文件完整性、Autoruns、基线对比。

### 44. 误报怎么处理？【高频】

**要点**：

- 确认规则逻辑与原始日志。
- 判断是否「真实但无害」。
- 加白名单/调阈值/加资产上下文。
- 记录原因，定期复审。
- 不要为了降误报而掩盖真实行为。

### 45. 告警研判流程？【高频】

**要点**：

- 看告警 → 原始日志 → 补上下文（资产/账号/情报）→ 关联前后事件。
- 判断误报/真实/未知。
- 定性定级 → 处置/升级 → 工单 → 复盘。
- 五要素：时间、资产、账号、行为、情报。

### 46. 日志缺失怎么办？

**要点**：

- 先确认采集/解析/时间/权限。
- 补数据源与审核策略。
- 用网络/身份/云日志补充。
- 监控日志健康与断流。
- 评估盲区风险。

### 47. 如何写一条检测规则？【高频】

**要点**：

- 明确目标与 ATT&CK 技术。
- 选择数据源与字段。
- 逻辑（单事件/阈值/序列）。
- 严重级别、误报场景、处置建议。
- 测试（正常/恶意/边界）。
- 版本管理与调优。

## 五、应急响应

### 48. 应急响应流程？【高频】

**要点**：

- NIST SP 800-61 r3（2025）：按 CSF 2.0 组织（Govern/Identify/Protect/Detect/Respond/Recover）；旧版 r2 常被概括为「准备 → 检测分析 → 遏制/根除/恢复 → 事后」。
- SANS：准备 → 识别 → 遏制 → 根除 → 恢复 → 经验。
- 实操：接警 → 确认 → 隔离 → 取证 → 排查 → 清除 → 恢复 → 复盘。

### 49. 主机失陷如何处置？【高频】

**要点**：

- 隔离网络（不关机）、保存内存/日志/样本。
- 排查入口、持久化、凭据、横向。
- 清除、修复、重置凭据、恢复/重装。
- 持续监控、复盘、补规则。

### 50. 勒索软件如何处置？【高频】

**要点**：

- 立即隔离、断网、不关机。
- 保存证据、样本、日志。
- 检查备份、评估扩散。
- 不支付赎金、通知管理层/法务。
- 重装、重置凭据（含 krbtgt）、恢复、监控。

### 51. 钓鱼邮件如何处置？

**要点**：

- 删除/隔离邮件、封禁发件人/域名。
- 分析邮件头、附件、URL。
- 确认谁点击/输入凭据。
- 重置账号、终端排查。
- 通知用户、加规则。

### 52. 账号失陷如何处置？

**要点**：

- 禁用账号、撤销会话、重置密码、重注册 MFA。
- 检查邮箱规则、OAuth 授权、权限。
- 查登录日志、关联主机。
- 通知相关方、复盘。

### 53. 数据泄露如何评估？

**要点**：

- 确认数据类型、范围、敏感度。
- 查访问/查询/外传日志。
- 评估合规通报义务。
- 通知法务/管理层。
- 阻断、修复、加强 DLP。

### 54. 证据如何保全？【高频】

**要点**：

- 易失优先：内存、网络、进程。
- 磁盘镜像、写保护、哈希。
- 证据链：谁/何时/何地/工具/哈希/存放。
- 不修改原始证据。
- 合法授权与隐私保护。

### 55. 如何隔离失陷主机？

**要点**：

- 网络隔离（EDR/交换机 ACL/安全组）。
- 保留管理通道与业务沟通。
- 禁用账号、封禁 IP。
- 不要直接关机（保留内存）。
- 记录处置动作。

### 56. 为什么不能直接关机？【高频】

**要点**：

- 内存中的进程、网络连接、凭据、恶意代码会丢失。
- 关机可能触发反取证/数据销毁。
- 应先采集内存与易失数据，再决定关机/隔离。
- 特殊情况（勒索扩散）可快速断网，但仍尽量保留证据。

### 57. 如何确定影响范围？

**要点**：

- 同账号、同漏洞、同网段、同时间。
- 登录、进程、服务、任务、网络。
- 情报与样本关联。
- 横向与数据访问。
- 业务影响评估。

### 58. 应急报告怎么写？

**要点**：

- 概述、时间线、影响范围、攻击链、处置、证据、根因、改进。
- 事实与推测分开。
- 结论先行。
- 附件哈希/日志/截图。
- 面向不同受众。

### 59. 复盘怎么做？

**要点**：

- 时间线与根因。
- 检测/响应/流程/工具问题。
- 改进项、负责人、截止时间。
- 更新 Playbook/规则/基线。
- 度量与跟踪。

### 60. 应急与取证的区别？

**要点**：

- 应急：控制、清除、恢复。
- 取证：保全证据、还原事实、可复现。
- 二者结合：先控制再取证，先取证再清除。
- 取证要求证据链与合法性。

## 六、工具与流量

### 61. Wireshark 常用过滤器？【高频】

**要点**：

- `ip.addr == x`、`tcp.port == 445`。
- `tcp.flags.syn == 1 && tcp.flags.ack == 0`。
- `http.request.method == "POST"`、`http.response.code >= 400`。
- `dns.qry.name contains "x"`、`tls.handshake.extensions_server_name`。
- 抓包过滤（BPF）与显示过滤不同。

### 62. 如何分析一个 PCAP？

**要点**：

- 看协议分布、会话、端点。
- 定位可疑 IP/域名/端口。
- 跟踪流、导出对象。
- 关联情报、提取 IOC。
- 形成时间线与结论。

### 63. NIDS 如何部署？

**要点**：

- 旁路 SPAN/TAP（检测），串联（阻断）。
- 出口、核心、关键区。
- 规则、性能、丢包、加密流量。
- 与 SIEM 集成。

### 64. EDR 与 AV 的区别？【高频】

**要点**：

- AV 特征为主；EDR 行为/IOA/ML/情报。
- EDR 采集进程/网络/文件/注册表，支持响应。
- EDR 也有局限（Agent、绕过、噪音）。
- 多层防御。

### 65. IOC、IOA、TTP 的区别？【高频】

**要点**：

- IOC：IP/域名/哈希等指标。
- IOA：行为指标。
- TTP：战术技术过程。
- 金字塔：TTP 最有价值，哈希最易变。

### 66. 金字塔模型？

**要点**：

- 哈希 → IP → 域名 → 主机/网络痕迹 → 工具 → TTP。
- 越往上越难改变，检测价值越高。
- 只封 IP 不够。

### 67. 威胁狩猎是什么？【高频】

**要点**：

- 主动假设攻击者已潜伏，用数据验证。
- 假设驱动/情报驱动/ATT&CK 驱动。
- 循环：假设 → 数据 → 分析 → 验证 → 产出。
- 产出规则/发现/数据缺口。
- 与 SOC 被动监控不同。

### 68. 溯源与归因的区别？

**要点**：

- 溯源：追踪攻击路径、来源、时间线。
- 归因：判断攻击者身份/组织，需多源情报。
- 归因要谨慎、标注置信度。
- 不反黑、不违法。

## 七、ATT&CK 与攻防

### 69. ATT&CK 是什么？【高频】

**要点**：

- MITRE 攻击行为知识库。
- 战术（目标）、技术（方法）、子技术、过程。
- 企业矩阵 14 战术。
- 用于检测映射、覆盖评估、狩猎、应急。

### 70. Kill Chain 七阶段？

**要点**：

- 侦察、武器化、投递、利用、安装、C2、目标行动。
- 打断一环即可防御。
- 与 ATT&CK 互补。

### 71. 如何把攻击映射到 ATT&CK？

**要点**：

- 识别行为（登录、进程、服务、网络）。
- 对应战术/技术。
- 找数据源与检测。
- 更新覆盖图。

### 72. 常见 TTP 及检测？

**要点**：

- T1059 脚本执行、T1053 计划任务、T1543 服务、T1003 凭据、T1021 远程服务、T1071 C2、T1486 勒索。
- 对应日志：4688/Sysmon 1、4698、7045、Sysmon 10、4624、代理/流量、文件加密。

## 八、场景题

### 73. 发现主机外连可疑 IP，怎么排查？【高频】

**要点**：

- 确认告警与进程（Sysmon 3/EDR）。
- 进程路径、命令行、父进程、签名、哈希。
- 情报查询 IP/域名，历史解析。
- 文件、注册表、服务、任务。
- 其他主机是否外连。
- 判断 C2/误报；隔离、取证、清除、重置、修复。

### 74. 员工收到钓鱼邮件，怎么办？

**要点**：

- 隔离/删除邮件，封禁发件人/域名。
- 分析邮件头、附件、URL。
- 确认是否点击/输入凭据。
- 重置账号、终端排查。
- 通知、培训、加规则。

### 75. 服务器 CPU 100%，怎么排查？【高频】

**要点**：

- top/ps 找高 CPU 进程。
- 路径、命令行、父进程、签名。
- 网络连接、矿池域名。
- cron/systemd/服务持久化。
- 挖矿处置：隔离、清除、修复入口、重置。

### 76. 网站被上传 Webshell，怎么处理？

**要点**：

- 隔离/下线、保存日志与样本。
- 定位文件、分析入口。
- 查 Web 进程子进程、持久化、横向。
- 清除、修复、重置凭据。
- 监控、复盘、补规则。

### 77. 域管账号异常登录，怎么排查？

**要点**：

- 4624 类型/来源/时间、4768/4769。
- 是否异地/非工作时段/异常设备。
- MFA、权限变更、组成员。
- 关联主机、LSASS 访问、Kerberos 攻击。
- 禁用、改密、撤销会话、排查横向。

### 78. 云 AccessKey 泄露，怎么办？

**要点**：

- 立即禁用/轮换密钥。
- 查云审计：API 调用、资源创建、IAM 变更。
- 检查后门账号/角色、对象存储、安全组。
- 评估数据访问与外传。
- 修复、监控、合规上报。
