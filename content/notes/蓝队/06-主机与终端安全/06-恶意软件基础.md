## 1. 什么是恶意软件

恶意软件（Malware）是意图破坏、窃取、控制或未授权访问的软件。

蓝队目标：

- 识别类型与家族
- 判断行为与影响
- 提取 IOC
- 清除与恢复
- 补充检测

> 严禁制作、传播恶意软件；样本分析仅在隔离环境进行。

---

## 2. 类型

| 类型 | 特点 | 例子/说明 |
|---|---|---|
| 病毒 | 感染文件/引导区 | 传统病毒 |
| 蠕虫 | 自我复制、网络传播 | WannaCry（结合漏洞） |
| 木马 | 伪装正常软件 | 远控木马 |
| 后门/RAT | 远程控制 | AsyncRAT、QuasarRAT |
| 勒索软件 | 加密文件索要赎金 | LockBit、BlackCat/ALPHV、Cl0p |
| 挖矿 | 占用资源挖矿 | XMRig 变种 |
| 信息窃取 | 窃取凭据/浏览器数据 | RedLine、Vidar |
| 僵尸网络 | 受控主机群 | Mirai（IoT） |
| Rootkit | 隐藏自身 | 内核/用户态 |
| 间谍软件 | 监控用户 | 商业间谍软件 |
| 广告软件 | 弹窗/劫持 | Adware |
| 无文件 | 内存/PowerShell/WMI | 不落地文件 |
| 勒索软件即服务 | RaaS | 产业化 |

## 3. 感染链

```text
投递（邮件/网页/U盘/漏洞/供应链）
  → 执行（宏/脚本/漏洞）
  → 载荷（Dropper/Loader）
  → 持久化
  → C2
  → 目标行动（窃取/加密/横向/破坏）
```

### 3.1 Dropper / Loader

- Dropper：释放载荷到磁盘
- Loader：加载载荷（可能无文件）
- Stager：分阶段下载
- Packer：加壳/混淆

### 3.2 常见投递

- 钓鱼邮件附件（宏、LNK、ISO、HTML）
- 恶意链接
- 漏洞利用（浏览器、Office、VPN、边缘设备）
- 供应链
- U 盘
- 水坑
- 盗版软件/破解工具

## 5. C2（命令与控制）

### 5.1 常见协议

- HTTP/HTTPS
- DNS
- TCP/UDP
- WebSocket
- ICMP
- 社交平台/云服务（隐蔽通道）
- P2P

### 5.2 特征

- 固定心跳/抖动
- 加密流量
- 域名/证书异常
- 小众端口
- 上传/下载模式
- 长连接/短连接
- 命名管道（SMB Beacon）
- 多级 C2

### 5.3 检测

- 流量：JA3/JA3S、SNI、证书、心跳
- DNS：长域名、高熵、TXT
- 代理：URL、UA
- 终端：进程、网络、内存
- 情报：IOC/TTP

## 6. 持久化

| 位置 | Windows | Linux |
|---|---|---|
| 启动项 | Run/RunOnce | profile、rc.local |
| 服务 | 服务/驱动 | systemd |
| 计划任务 | Task Scheduler | cron/systemd timer |
| 账号 | 后门账号 | UID 0、SSH key |
| WMI | 事件订阅 | — |
| DLL | 劫持/侧加载 | ld.so.preload |
| 浏览器 | 扩展 | — |
| 容器 | — | 恶意镜像/特权容器 |

> 详见 [权限维持与检测](../08-威胁框架与攻防对抗/05-权限维持与检测.md)。

## 7. 规避技术（防御视角）

- 加壳/混淆
- 加密/编码
- 反调试/反沙箱
- 无文件/内存加载
- LOLBAS
- 进程注入/挖空
- 签名伪造/盗用
- 时间延迟
- 环境检测（虚拟机/沙箱）
- 关闭安全软件
- BYOVD

蓝队应对：

- 行为检测
- 内存扫描
- 沙箱
- 多源关联
- 威胁情报
- 安全加固

## 8. 检测数据源

| 数据源 | 能发现什么 |
|---|---|
| EDR/AV | 已知/行为/内存 |
| Sysmon | 进程、网络、文件、注册表 |
| Windows 事件 | 登录、服务、任务、PowerShell |
| Linux audit | 命令、文件、网络 |
| 流量 | C2、下载、外传 |
| DNS | 恶意域名、隧道 |
| 代理 | URL、UA |
| 邮件网关 | 钓鱼、附件 |
| 沙箱 | 动态行为 |
| 情报 | IOC/TTP |

## 9. 响应

1. 隔离主机（不关机）。
2. 保存内存、进程、网络、日志、样本。
3. 识别类型/家族（谨慎，勿依赖单一引擎）。
4. 确定入口与影响范围。
5. 清除持久化、文件、账号。
6. 重置凭据。
7. 修复入口。
8. 恢复/重装。
9. 持续监控。
10. 复盘与规则更新。

---

## 10. 实操

1. 在隔离环境分析公开恶意样本（如 MalwareBazaar 的教育样本）。
2. 用沙箱查看行为报告。
3. 提取 IOC 并查询 VT。
4. 用 YARA 扫描样本目录。
5. 用 Sysmon 观察样本行为。
6. 写一份样本分析报告。
7. 模拟一次恶意软件应急。

> 仅在隔离环境，遵守法律与平台条款。
