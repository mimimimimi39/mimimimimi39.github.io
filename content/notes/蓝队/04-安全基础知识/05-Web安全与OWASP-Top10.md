## 1. OWASP 是什么

OWASP（Open Worldwide Application Security Project）是开放社区，发布 Web 安全指南、工具与标准。**OWASP Top 10 是风险意识文档，不是完整漏洞清单**，也不是测试标准（测试看 WSTG）。

---

## 2. OWASP Top 10 2021

| 编号 | 风险 | 一句话 |
|---|---|---|
| A01 | 访问控制失效（Broken Access Control） | 用户能访问不该访问的资源/功能 |
| A02 | 加密机制失效（Cryptographic Failures） | 敏感数据未加密/弱加密/密钥管理不当 |
| A03 | 注入（Injection） | SQL、命令、LDAP、模板等注入 |
| A04 | 不安全设计（Insecure Design） | 设计阶段缺少安全控制 |
| A05 | 安全配置错误（Security Misconfiguration） | 默认配置、暴露后台、错误信息 |
| A06 | 易受攻击和过时的组件（Vulnerable and Outdated Components） | 依赖/框架/系统未打补丁 |
| A07 | 身份识别和认证失败（Identification and Authentication Failures） | 弱口令、会话管理、MFA 缺失 |
| A08 | 软件和数据完整性失效（Software and Data Integrity Failures） | 不安全的反序列化、供应链、更新 |
| A09 | 安全日志和监控失效（Security Logging and Monitoring Failures） | 日志缺失、告警缺失、响应缺失 |
| A10 | 服务端请求伪造（SSRF） | 服务端被诱导访问内网/元数据 |

## 3. 逐项讲解（蓝队视角）

### A01 访问控制失效

**表现**：

- 通过修改 URL/参数访问他人数据（IDOR）
- 普通用户访问管理员接口
- 目录列表、备份文件可下载
- CORS 配置过宽
- 缺少服务端权限校验，仅前端隐藏按钮

**检测**：

- 大量 403/401 后出现 200
- 同一账号访问异常资源 ID
- 越权访问日志
- 管理接口被非管理员访问

**防御**：

- 服务端强制鉴权
- 默认拒绝
- 资源归属校验
- 最小权限
- 定期权限审计

---

### A02 加密机制失效

**表现**：

- HTTP 明文传输敏感数据
- 弱算法（MD5、SHA-1、DES、RC4）
- 硬编码密钥
- 证书校验关闭
- 敏感数据明文存储

**检测**：

- 明文协议流量
- 证书异常
- 代码仓库密钥泄露
- 数据库敏感字段明文

**防御**：

- 全站 HTTPS/HSTS
- 强算法与正确模式
- 密钥管理（KMS/HSM）
- 敏感数据加密/脱敏
- 禁止硬编码密钥

---

### A03 注入

包括 SQL、NoSQL、OS 命令、LDAP、XPath、模板注入等。

**检测**：

- 输入含特殊字符/关键字
- 数据库错误
- 异常子进程
- 响应时间异常（盲注）
- WAF 告警

**防御**：

- 参数化查询/预编译
- 输入校验与白名单
- 最小权限
- 安全 API
- WAF 作为补充

> 详见 [SQL 注入](06-SQL注入.md) 与 [文件上传与命令注入](08-文件上传与命令注入.md)。

---

### A04 不安全设计

**表现**：

- 业务逻辑可被绕过（如负数金额、重复领券）
- 缺少速率限制
- 密码找回流程可预测
- 威胁建模缺失

**检测**：

- 异常业务操作序列
- 高频请求
- 异常参数组合

**防御**：

- 威胁建模
- 安全设计评审
- 业务规则服务端校验
- 速率限制与反自动化
- 安全开发生命周期（SDL）

---

### A05 安全配置错误

**表现**：

- 默认账号/密码
- 管理后台暴露公网
- 目录列表
- 错误堆栈泄露
- 云存储公开
- 不必要的服务/端口
- 缺少安全头

**检测**：

- 暴露面扫描
- 配置核查
- 异常访问管理路径
- 云配置审计

**防御**：

- 安全基线
- 最小化安装
- 关闭默认账号/示例
- 统一配置管理
- 定期核查

---

### A06 易受攻击和过时的组件

**表现**：

- 框架/库/中间件版本过旧
- 未及时打补丁
- 使用已停止维护的组件
- 依赖链漏洞

**检测**：

- SBOM/依赖扫描
- 版本指纹
- 漏洞情报（KEV）
- 异常利用流量

**防御**：

- 资产与组件清单
- 补丁管理
- 依赖扫描
- 移除不必要组件
- 订阅安全公告

---

### A07 身份识别和认证失败

**表现**：

- 弱口令
- 无 MFA
- 会话固定
- Session 不过期
- 密码找回缺陷
- 用户名枚举

**检测**：

- 登录失败/成功模式
- 异常地点/设备
- 会话异常
- 撞库特征

**防御**：

- MFA
- 强密码策略
- 安全会话管理
- 登录限速
- 凭据泄露监控
- 账号生命周期管理

---

### A08 软件和数据完整性失效

**表现**：

- 不安全的反序列化
- 未校验的更新/插件
- 供应链投毒
- CI/CD 权限过宽
- 代码签名缺失

**检测**：

- 异常反序列化流量
- 未签名二进制
- 依赖变更
- CI/CD 异常

**防御**：

- 避免原生反序列化
- 签名与校验
- SBOM
- 供应链安全
- CI/CD 隔离与审计

> 详见 [反序列化漏洞](10-反序列化漏洞.md)。

---

### A09 安全日志和监控失效

**表现**：

- 关键事件未记录
- 日志未集中
- 无告警
- 告警不处理
- 日志可被篡改/删除
- 留存不足

**检测**：

- 日志缺口
- 日志清除事件（1102/104）
- 告警积压
- MTTD/MTTR 恶化

**防御**：

- 日志规范与集中
- 关键事件审计
- 告警与值守
- 日志完整性保护
- 演练与复盘

> 这是蓝队最应该关注的一项：**没有日志就没有检测**。

---

### A10 SSRF

**表现**：

- 服务端根据用户输入请求 URL
- 访问内网服务、云元数据（`169.254.169.254`）
- 支持 `file://`、`gopher://`、`dict://` 等协议
- 绕过黑名单（进制、域名、重定向）

**检测**：

- 内网访问日志
- 元数据服务访问
- 异常协议
- 外连内网地址

**防御**：

- URL 白名单
- 禁止不必要协议
- 解析后校验 IP
- 网络隔离
- 元数据服务加固（IMDSv2）

> 详见 [SSRF 与 XXE](09-SSRF与XXE.md)。

## 4. 蓝队如何用 OWASP Top 10

1. **资产梳理**：哪些 Web 应用、API、管理后台暴露。
2. **日志覆盖**：Web 访问日志、WAF、应用日志、数据库日志。
3. **检测规则**：针对 A03/A01/A10 等高频风险。
4. **漏洞管理**：结合 CVE/CVSS/KEV 排序。
5. **应急准备**：Webshell、注入、数据泄露处置流程。
6. **复盘**：每次事件映射到 OWASP 类别，改进控制。

---

## 5. Web 攻击检测数据源

| 数据源 | 能看到什么 |
|---|---|
| Web 访问日志 | 请求方法、URI、状态码、UA、响应大小 |
| WAF 日志 | 规则命中、拦截、误报 |
| 应用日志 | 业务操作、异常堆栈 |
| 数据库日志 | SQL、错误、慢查询 |
| 主机日志 | Web 进程子进程、文件落地 |
| 流量 | 请求响应内容、Webshell、C2 |
| EDR | 进程、文件、网络、内存 |
| 情报 | 恶意 IP/域名/样本 |

---

## 6. 实操

1. 在 DVWA 或 Juice Shop 中复现 SQLi、XSS、文件上传（仅本地）。
2. 对照 Web 日志，找出攻击请求。
3. 用 WAF（如 ModSecurity + OWASP CRS）观察拦截日志。
4. 为每个 OWASP 类别写一张「检测卡片」。
5. 用 Nuclei 扫描本地靶场（仅授权）。
6. 阅读一次真实 Web 入侵报告，映射到 OWASP 类别。
