## 1. 为什么蓝队要学云与容器

- 越来越多业务上云，传统边界模糊。
- 云配置错误（对象存储公开、IAM 过宽）是高频问题。
- 容器与 K8s 成为主流部署方式，逃逸与未授权访问风险增加。
- 云审计日志是云上应急的核心数据源。

> 初级岗位不要求精通云安全，但理解责任共担、IAM、云日志、容器基础会明显加分。

---

## 2. 责任共担模型

```text
云厂商：物理设施、虚拟化、基础网络、托管服务底层
客户：数据、身份与权限、配置、应用、操作系统（IaaS）、网络策略
```

关键：**云安全的大部分问题来自客户侧配置与身份管理**。

## 3. 身份与权限（IAM）

### 3.1 核心概念

| 概念 | 说明 |
|---|---|
| 账号（Account） | 云账号/租户 |
| 用户（User） | 长期身份 |
| 角色（Role） | 可被扮演的临时身份 |
| 策略（Policy） | 权限声明 |
| 访问密钥（AccessKey） | 程序访问凭据 |
| MFA | 多因素认证 |
| 联合身份 | SSO/SAML/OIDC |

### 3.2 常见风险

- AccessKey 泄露（代码仓库、配置文件、日志）
- 权限过大（`*:*`）
- 长期密钥不轮换
- 未启用 MFA
- 根账号日常使用
- 角色信任策略过宽
- 跨账号信任配置错误

### 3.3 检测

- 云审计日志中的 `CreateAccessKey`、`AttachUserPolicy`、`AssumeRole`
- 异常地域/时间/UA 的 API 调用
- 根账号登录
- 密钥在 GitHub 泄露（GitHub Secret Scanning）
- 异常权限提升

## 4. 常见云服务与风险

### 4.1 对象存储

风险：

- Bucket 公开可读/可写
- 目录遍历
- 未授权上传
- 静态网站托管配置错误
- 日志未开启

检测：

- 存储访问日志
- 公开访问配置变更
- 异常下载量
- 外链分享

### 4.2 计算实例

风险：

- 安全组开放 0.0.0.0/0
- 弱口令/密钥泄露
- 未打补丁
- 元数据服务被 SSRF 利用
- 快照/镜像泄露

### 4.3 元数据服务

- `169.254.169.254`（AWS）
- `100.100.100.200`（阿里云）
- `metadata.tencentyun.com`（腾讯云）
- `metadata.google.internal`（GCP）

风险：SSRF 获取临时凭据。

防御：IMDSv2、限制访问、网络隔离、最小角色权限。

### 4.4 Serverless

- 函数权限过宽
- 事件注入
- 依赖漏洞
- 日志不足

### 4.5 数据库与中间件

- 公网暴露
- 弱口令
- 未授权访问
- 备份公开

## 5. 云审计与日志

| 云 | 日志 |
|---|---|
| AWS | CloudTrail、VPC Flow Logs、GuardDuty、S3 Access Logs |
| Azure | Activity Log、Microsoft Defender for Cloud、NSG Flow Logs |
| 阿里云 | 操作审计 ActionTrail、云安全中心、VPC Flow Log |
| 腾讯云 | 云审计 CloudAudit、云防火墙、日志服务 CLS |
| GCP | Cloud Audit Logs、VPC Flow Logs、Security Command Center |

蓝队关注：

- 登录与 MFA 事件
- IAM 变更
- 安全组/网络变更
- 存储权限变更
- 密钥创建/使用
- 异常 API 调用
- 资源创建（挖矿）
- 日志配置变更/删除

## 6. 容器基础

### 6.1 容器与虚拟机

| 维度 | 容器 | 虚拟机 |
|---|---|---|
| 隔离 | 进程级（namespace 隔离 + cgroup 资源限制） | 硬件级 |
| 启动 | 秒级 | 分钟级 |
| 内核 | 共享宿主内核 | 独立内核 |
| 安全边界 | 较弱 | 较强 |

### 6.2 Docker 核心概念

- 镜像（Image）
- 容器（Container）
- 仓库（Registry）
- Dockerfile
- Volume
- Network
- Docker Socket（`/var/run/docker.sock`）

### 6.3 常见风险

| 风险 | 说明 |
|---|---|
| 容器逃逸 | 特权容器、挂载宿主目录、内核漏洞 |
| Docker Socket 暴露 | 控制宿主 |
| 镜像投毒 | 恶意基础镜像/依赖 |
| 敏感信息硬编码 | 镜像层中的密钥 |
| 未限制资源 | 挖矿、DoS |
| 未授权 API | 2375/2376 暴露 |
| 容器内 root | 提权风险 |
| 日志缺失 | 难以检测 |

### 6.4 容器检测

- 异常容器创建/删除
- 特权容器（`--privileged`）
- 挂载 `/var/run/docker.sock`、`/`、`/proc`
- 容器内异常进程、外连、挖矿
- 镜像来源不可信
- 运行时逃逸行为
- K8s 审计日志异常

## 7. Kubernetes 基础

### 7.1 核心组件

| 组件 | 作用 |
|---|---|
| API Server | 控制面入口 |
| etcd | 键值存储 |
| Scheduler | 调度 |
| Controller Manager | 控制器 |
| kubelet | 节点代理 |
| kube-proxy | 网络代理 |
| Pod | 最小部署单元 |
| Service | 服务访问 |
| Ingress | 入口 |
| Namespace | 逻辑隔离 |
| RBAC | 权限控制 |
| ServiceAccount | Pod 身份 |

### 7.2 常见风险

- API Server 暴露公网/匿名访问
- RBAC 过宽（cluster-admin）
- ServiceAccount Token 泄露
- Secret 未加密
- 特权 Pod
- hostPath 挂载
- 镜像未扫描
- NetworkPolicy 缺失
- 供应链投毒

### 7.3 检测

- K8s 审计日志
- 异常 `exec`/`attach`/`port-forward`
- 创建特权 Pod
- 读取 Secret
- RBAC 变更
- 异常镜像拉取
- 容器外连

## 8. 云上应急响应

1. 确认受影响账号、地域、资源。
2. 保存云审计日志、流量日志、快照。
3. 隔离受影响实例（安全组/网络 ACL）。
4. 禁用/轮换泄露的 AccessKey。
5. 检查 IAM 变更、后门账号、角色信任。
6. 检查对象存储公开与数据访问。
7. 检查挖矿/异常计费。
8. 修复配置，开启日志与告警。
9. 复盘与合规上报。

> 云上证据易被删除，优先开启日志与快照；操作前确认授权与流程。

## 9. 云安全加固清单

- [ ] 根账号启用 MFA，不日常使用
- [ ] 最小权限 IAM
- [ ] AccessKey 轮换与泄露扫描
- [ ] 安全组最小开放
- [ ] 对象存储默认私有
- [ ] 开启云审计与流量日志
- [ ] 元数据服务加固
- [ ] 镜像扫描与签名
- [ ] 容器非 root、只读文件系统
- [ ] 禁止特权容器与危险挂载
- [ ] K8s RBAC 最小权限
- [ ] NetworkPolicy 分段
- [ ] 密钥管理服务
- [ ] 备份与恢复演练

## 10. 实操

1. 用 Docker 运行一个容器，查看 namespace/cgroup。
2. 用 `docker inspect` 查看挂载与权限。
3. 用 Trivy 扫描镜像漏洞。
4. 在本地 K8s（kind/minikube）中创建 Pod，查看审计日志。
5. 用云厂商免费额度体验对象存储与审计日志（注意费用）。
6. 写一条检测规则：安全组开放 22 端口到 0.0.0.0/0。
7. 模拟 AccessKey 泄露的排查流程。

> 云上操作注意费用与授权，实验后及时清理资源。
