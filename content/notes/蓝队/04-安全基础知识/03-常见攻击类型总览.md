## 1. 为什么要先建立攻击地图

初学者容易陷入「学一个漏洞忘一个漏洞」。先建立攻击地图，知道攻击者从哪些入口进来、用什么手法、留下什么痕迹，再逐个深入。

## 2. 按目标分类

### 2.1 Web 应用攻击

| 攻击 | 简述 | 主要数据源 |
|---|---|---|
| SQL 注入 | 通过输入拼接执行 SQL | Web 日志、WAF、数据库日志 |
| XSS | 注入恶意脚本 | Web 日志、CSP 报告、浏览器 |
| CSRF | 诱导用户发起请求 | Web 日志、Referer、Token |
| 文件上传 | 上传 Webshell/恶意文件 | Web 日志、文件监控、AV |
| 命令注入 | 拼接系统命令 | Web 日志、主机进程 |
| SSRF | 服务端发起内网请求 | Web 日志、内网流量 |
| XXE | XML 外部实体 | Web 日志、文件访问 |
| 反序列化 | 构造恶意序列化数据 | 应用日志、流量、EDR |
| 路径穿越 | 读取任意文件 | Web 日志、文件访问 |
| 越权 | 访问未授权资源 | 应用日志、访问控制 |
| 业务逻辑漏洞 | 绕过业务规则 | 应用日志、业务数据 |
| API 滥用 | 未授权/高频调用 | API 网关日志 |

### 2.2 主机与终端攻击

| 攻击 | 简述 | 主要数据源 |
|---|---|---|
| 恶意软件 | 木马、勒索、挖矿、RAT | EDR、AV、Sysmon、文件 |
| 无文件攻击 | PowerShell、WMI、注册表 | Sysmon、PowerShell 日志、EDR |
| 提权 | 利用漏洞/配置提升权限 | 4688、EDR、系统日志 |
| 持久化 | 服务、计划任务、启动项 | 7045、4698、Sysmon 13 |
| 凭据窃取 | LSASS、SAM、浏览器 | Sysmon 10、EDR、4624 |
| 进程注入 | 将代码注入合法进程 | Sysmon 8/10、EDR |
| Rootkit | 隐藏自身 | 内核日志、完整性检查 |
| 勒索 | 加密文件、索要赎金 | 文件监控、EDR、备份 |

### 2.3 网络攻击

| 攻击 | 简述 | 主要数据源 |
|---|---|---|
| 端口扫描 | 探测开放服务 | 防火墙、Zeek、Suricata、NetFlow |
| 暴力破解 | 猜测口令 | 认证日志、IDS |
| DDoS | 耗尽资源 | NetFlow、流量设备 |
| ARP 欺骗 | 中间人 | ARP 表、流量 |
| DNS 劫持/投毒 | 篡改解析 | DNS 日志、流量 |
| DNS 隧道 | 隐蔽传输 | DNS 日志、Zeek |
| 中间人 | 截获通信 | 流量、证书 |
| 横向移动 | 内网扩散 | 主机日志、流量 |
| C2 | 远程控制 | 代理、流量、DNS |
| 数据外传 | 窃取数据 | DLP、流量、代理 |

### 2.4 身份与账号攻击

| 攻击 | 简述 | 主要数据源 |
|---|---|---|
| 弱口令 | 简单密码 | 登录日志 |
| 撞库 | 复用泄露密码 | 登录日志、情报 |
| 口令喷洒 | 少量密码尝试多账号 | 4625、应用日志 |
| Pass-the-Hash | 使用 NTLM 哈希 | 4624 类型 3、Sysmon |
| Kerberoasting | 请求服务票据离线破解 | 4769、EDR |
| AS-REP Roasting | 获取无预认证账号哈希 | 4768 |
| Golden Ticket | 伪造 TGT | 4768/4769、DC 日志 |
| MFA 疲劳 | 反复推送诱导确认 | MFA 日志、帮助台 |
| 会话劫持 | 窃取 Cookie/Token | Web 日志、EDR |

### 2.5 社会工程与钓鱼

| 攻击 | 简述 | 主要数据源 |
|---|---|---|
| 钓鱼邮件 | 诱导点击/输入凭据 | 邮件网关、代理、EDR |
| 鱼叉式钓鱼 | 针对特定人 | 邮件网关、终端 |
| 恶意附件 | 宏、LNK、ISO、HTML | 邮件网关、EDR |
| 二维码钓鱼 | 引导手机访问 | 邮件网关、代理 |
| 电话诈骗 | 冒充 IT/领导 | 流程、培训 |
| 水坑攻击 | 入侵常访问网站 | Web 日志、终端 |
| 商业邮件诈骗（BEC） | 冒充供应商/领导转账 | 邮件日志、财务流程 |

### 2.6 供应链与第三方

| 攻击 | 简述 | 主要数据源 |
|---|---|---|
| 软件供应链 | 篡改/植入恶意代码 | 代码签名、SBOM、终端 |
| 依赖投毒 | 恶意 npm/PyPI 包 | 包管理日志、终端 |
| 供应商入侵 | 通过第三方进入 | 第三方访问日志 |
| 硬件供应链 | 设备植入 | 资产、固件校验 |
| 云服务配置错误 | 存储桶公开、IAM 过宽 | 云审计日志 |

### 2.7 云与容器

| 攻击 | 简述 | 主要数据源 |
|---|---|---|
| 云账号劫持 | 密钥泄露、MFA 绕过 | CloudTrail/云审计 |
| 对象存储泄露 | Bucket 公开 | 云存储日志 |
| 元数据服务滥用 | SSRF 获取临时凭据 | 云日志、流量 |
| 容器逃逸 | 利用配置/漏洞 | 容器运行时日志 |
| K8s 未授权 | API Server 暴露 | K8s 审计日志 |
| 镜像投毒 | 恶意镜像 | 镜像扫描、运行时 |

### 2.8 内部威胁与物理

| 攻击 | 简述 | 主要数据源 |
|---|---|---|
| 内部人员泄露 | 合法权限滥用 | DLP、访问日志 |
| 权限滥用 | 管理员越权 | 审计日志 |
| 离职风险 | 数据带走 | DLP、账号生命周期 |
| 物理入侵 | 接触设备 | 门禁、监控 |
| 尾随 | 跟随进入 | 门禁、监控 |

## 3. 按攻击链分类

```text
侦察 → 武器化 → 投递 → 利用 → 安装 → C2 → 目标行动
```

| 阶段 | 常见行为 | 蓝队检测 |
|---|---|---|
| 侦察 | 扫描、子域枚举、OSINT | 防火墙、Web 日志、情报 |
| 武器化 | 制作木马、钓鱼页面 | 情报、沙箱 |
| 投递 | 邮件、U 盘、水坑 | 邮件网关、代理、终端 |
| 利用 | 漏洞、宏、弱口令 | EDR、WAF、日志 |
| 安装 | 持久化、后门 | 服务、计划任务、注册表 |
| C2 | 心跳、远程控制 | 流量、DNS、代理 |
| 目标行动 | 横向、提权、外传、破坏 | 主机日志、流量、DLP |

> 对应 [网络杀伤链](https://www.lockheedmartin.com/en-us/capabilities/cyber/cyber-kill-chain.html) 与 [MITRE ATT&CK](https://attack.mitre.org/)。

## 4. 攻击者视角 vs 蓝队视角

| 问题 | 攻击者 | 蓝队 |
|---|---|---|
| 入口 | 哪个最薄弱 | 哪个暴露面最大 |
| 权限 | 如何最快提权 | 谁有特权、是否异常 |
| 持久化 | 如何不被发现 | 哪些位置可自启动 |
| 横向 | 如何复用凭据 | 哪些登录/连接异常 |
| 外传 | 如何绕过检测 | 哪些流量异常 |
| 清除 | 如何删日志 | 日志是否完整、是否有外部副本 |

## 5. 蓝队数据源地图

| 数据源 | 能看到什么 | 典型问题 |
|---|---|---|
| Windows 安全日志 | 登录、账号、权限、进程 | 审核策略是否开启 |
| Sysmon | 进程、网络、文件、注册表 | 配置是否覆盖 |
| Linux auth/audit | 登录、sudo、命令 | 日志是否集中 |
| EDR | 终端行为、响应 | 告警是否调优 |
| 防火墙 | 五元组、拦截 | NAT 后溯源 |
| WAF | HTTP 攻击 | 误报、加密绕过 |
| NIDS | 网络攻击特征 | 加密流量 |
| DNS | 域名查询 | 隧道、DGA |
| 代理 | URL、UA、上传下载 | HTTPS 可见性 |
| 邮件网关 | 发件人、附件、URL | 钓鱼绕过 |
| 云审计 | API 调用、IAM | 日志是否开启 |
| 应用日志 | 业务行为 | 格式不统一 |
| 威胁情报 | IOC/TTP | 时效与准确性 |

## 6. 攻击趋势（了解）

- 勒索软件产业化、双重勒索
- 钓鱼与社工持续高效
- 身份攻击（MFA 疲劳、令牌窃取）
- 供应链与第三方风险
- 云配置错误与容器安全
- 无文件与 Living-off-the-Land
- 边缘设备漏洞（VPN、防火墙、邮件网关）
- AI 辅助攻击与防御

> 趋势会变，但「入口、权限、持久化、横向、外传」的基本盘长期不变。

## 7. 实操

1. 选一个真实攻击报告，按目标/攻击链分类。
2. 为每种攻击列出 1-2 个检测数据源。
3. 画一张你所在环境的「攻击面地图」。
4. 用 ATT&CK 标注 5 个常见技术。
5. 写一个「如果我是攻击者，会从哪里进来」的分析。
