## 1. 什么是威胁情报

威胁情报（Threat Intelligence）是关于攻击者、攻击活动、恶意基础设施、TTP 的**可操作信息**，用于支持决策与防御。

不是「收集一堆 IOC」，而是回答：

- 谁在攻击我们？
- 他们用什么手法？
- 我们是否已被攻击？
- 我们应该优先防什么？

---

## 2. 情报层级

| 层级 | 受众 | 内容 | 例子 |
|---|---|---|---|
| 战略情报 | 管理层 | 威胁趋势、行业风险 | 勒索软件趋势报告 |
| 运营情报 | 安全运营 | 攻击活动、Campaign | 某 APT 正在攻击金融行业 |
| 战术情报 | 分析师 | TTP、工具、流程 | ATT&CK 技术、攻击链 |
| 技术情报 | 检测系统 | IOC、指纹、规则 | IP、域名、哈希、JA3 |

> 越往下越具体、越易过期；越往上越抽象、越持久。**TTP 最持久**。

---

## 3. IOC、IOA、TTP

| 类型 | 含义 | 例子 | 持久性 |
|---|---|---|---|
| IOC | 入侵指标 | IP、域名、URL、哈希 | 低 |
| IOA | 入侵行为指标 | 异常进程、横向行为 | 中 |
| TTP | 战术、技术、过程 | ATT&CK 技术 | 高 |

### 3.1 IOC 类型

- 网络：IP、域名、URL、JA3、证书
- 主机：文件哈希、文件名、路径、注册表、服务名
- 邮件：发件人、主题、附件哈希
- 账号：恶意账号、邮箱

> YARA、Sigma 是检测规则格式，不是 IOC；IOC 是可观测指标（IP、域名、URL、哈希、证书等）。

### 3.2 金字塔模型（Pyramid of Pain）

David J. Bianco 提出：

```text
TTP（最难改变，最有价值）
  ↑
工具
  ↑
主机/网络痕迹
  ↑
域名
  ↑
IP
  ↑
哈希（最易改变，价值最低）
```

> 只封 IP/哈希，攻击者改一下就能绕过。检测 TTP 才能真正提高攻击成本。

## 4. 情报来源

### 4.1 开源（OSINT）

- 厂商博客：Microsoft、Google TAG、Unit 42、Securelist、Cisco Talos
- 事件报告：The DFIR Report、Volexity、Mandiant
- 漏洞库：NVD、CVE、KEV
- 恶意样本/URL：VirusTotal、MalwareBazaar、URLhaus、ThreatFox
- 域名/IP：OTX、abuse.ch、Shodan、Censys
- 社区：MISP 社区、Twitter/X、安全论坛
- 国内：微步在线、奇安信威胁情报中心、360 威胁情报中心、绿盟 NTI

### 4.2 商业情报

- 厂商订阅（Recorded Future、Mandiant、CrowdStrike 等）
- 行业 ISAC
- 暗网监控
- 品牌保护

### 4.3 内部情报

- 自己的事件
- 蜜罐
- 沙箱
- 邮件网关
- EDR 遥测
- 漏洞扫描

> 内部情报往往最贴合自身环境，价值最高。

## 5. 情报生命周期

```text
需求规划 → 收集 → 处理 → 分析 → 分发 → 反馈
```

| 阶段 | 关键问题 |
|---|---|
| 规划 | 我们需要什么情报？ |
| 收集 | 从哪里获取？ |
| 处理 | 如何清洗、标准化？ |
| 分析 | 是否可信？是否相关？ |
| 分发 | 给谁？怎么用？ |
| 反馈 | 是否有用？如何改进？ |

## 7. IOC 质量评估

一个可用 IOC 应具备：

- **可信**：来源可靠、经过验证
- **相关**：与你的行业/资产相关
- **新鲜**：未过期
- **可操作**：能落地到检测/阻断
- **上下文**：攻击活动、家族、时间

### 7.1 常见问题

- 共享 IP（CDN、云）误封
- IOC 过期
- 低置信度
- 情报污染
- 缺乏上下文
- 只封 IP 不检测 TTP

### 7.2 处理流程

```text
收集 → 去重 → 验证（多源） → 富化（WHOIS/被动DNS/证书）
→ 评分 → 入库 → 下发（阻断/检测/狩猎） → 过期管理
```

## 8. 情报落地

| 场景 | 用法 |
|---|---|
| 阻断 | 防火墙/WAF/DNS/代理封禁 |
| 检测 | SIEM 规则匹配 IOC |
| 狩猎 | 用 IOC/TTP 主动搜索 |
| 应急 | 判断样本/IP 是否恶意 |
| 漏洞 | 判断是否被在野利用（KEV） |
| 决策 | 行业威胁趋势 |

### 8.1 示例：SIEM 情报匹配

```spl
index=proxy
| lookup threat_intel ip AS dest_ip OUTPUT threat_type, confidence
| where isnotnull(threat_type) AND confidence > 80
| table _time src_ip dest_ip url threat_type confidence
```

> 实际需处理 IP 共享、情报时效、白名单等问题。

## 10. 蓝队日常

1. 每日查看新情报（KEV、厂商报告、行业预警）。
2. 将高置信 IOC 下发阻断/检测。
3. 用 TTP 更新检测规则。
4. 对告警中的 IP/域名/哈希做情报查询。
5. 跟踪攻击活动与行业趋势。
6. 评估情报有效性（命中率、误报）。
7. 清理过期 IOC。

---

## 11. 实操

1. 在 VirusTotal 查询一个公开样本哈希，阅读报告。
2. 在 OTX 查看一个 IP 的情报。
3. 在 CISA KEV 查看最近漏洞。
4. 用 MISP 导入/查看 IOC（本地）。
5. 写一条 SIEM 情报匹配规则。
6. 为一个攻击活动整理 IOC + TTP 卡片。
7. 评估 10 个 IOC 的质量。

> 不要上传企业敏感数据到公开平台。
