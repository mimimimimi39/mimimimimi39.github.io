
## 1. 蓝队是什么

蓝队（Blue Team）是组织内部负责**防御、检测、响应、溯源与持续改进**的安全团队。与红队（模拟攻击）相对，蓝队的目标不是「打败红队」，而是：

1. **看得见**：资产、账号、日志、流量、漏洞是否可见。
2. **拦得住**：边界、终端、身份、应用是否有有效控制。
3. **查得清**：告警能否研判，事件能否定性、定级、定位。
4. **恢复得快**：能否遏制、清除、恢复并复盘。
5. **防得久**：能否通过基线、情报、狩猎、演练持续提升。

蓝队不是单一岗位，而是一组岗位的集合：

| 岗位 | 核心工作 | 入门难度 | 常见雇主 |
|---|---|---|---|
| SOC 分析师 L1 | 盯告警、初判、工单、升级 | 低 | 甲方 SOC、MSSP、安全厂商 |
| SOC 分析师 L2 | 深入研判、关联分析、处置建议 | 中 | 同上 |
| 应急响应工程师 | 入侵排查、遏制、清除、取证 | 中高 | 安全厂商、甲方、咨询公司 |
| 安全运营工程师 | SIEM 规则、日志接入、告警调优、SOAR | 中 | 甲方、MSSP |
| 威胁情报分析师 | IOC/TTP 生产与落地、情报运营 | 中高 | 厂商、金融、大型甲方 |
| 威胁狩猎工程师 | 假设驱动狩猎、检测工程 | 高 | 成熟甲方、厂商 |
| 安全服务工程师 | 基线核查、风险评估、等保、驻场 | 低中 | 安全厂商、测评机构 |
| 安全研发工程师 | 检测平台、自动化、EDR/SIEM 开发 | 高 | 厂商、大厂 |

> 渗透测试、红队属于攻击侧岗位，但蓝队必须理解攻击者视角。本路线会在「攻防对抗」模块讲攻击原理，目的始终是**检测与防御**。

## 2. 目标能力模型

一名可实习的蓝队初级人员，应具备以下能力：

| 能力域 | 实习要求 | 对应模块 |
|---|---|---|
| 网络与协议 | 看懂 TCP/IP、HTTP/DNS/TLS，能用 Wireshark 过滤 | 02、07 |
| 操作系统 | Linux 常用命令、Windows 账号/服务/注册表/事件日志 | 02、06 |
| 编程与数据 | Python 读写日志/调 API，PowerShell/Bash 做排查，SQL 查日志 | 03 |
| 安全基础 | 理解常见 Web 漏洞、密码学常识、漏洞管理 | 04 |
| 日志与检测 | 知道常见日志源、关键事件 ID、告警研判流程 | 05、06 |
| 应急响应 | 掌握准备-检测-遏制-根除-恢复-复盘流程 | 05 |
| 流量分析 | 能识别扫描、爆破、Webshell、C2 流量特征 | 07 |
| 威胁框架 | 能用 ATT&CK 描述攻击行为并映射检测 | 08 |
| 工具使用 | SIEM、EDR、Wireshark、Sysmon、VT、沙箱等 | 05-08 |
| 沟通与文档 | 写清楚工单、事件报告、复盘报告 | 05、10 |
| 法律合规 | 明确授权边界、证据保全、个人信息保护 | 04、05、10 |

## 3. 总体学习路线

```text
阶段 0  认知与准备        1-2 周    岗位认知、学习方法、实验环境、法律边界
   │
阶段 1  计算机与网络基础  6-8 周    计算机组成、Linux、Windows、TCP/IP、HTTP、DNS、数据库
   │
阶段 2  编程与数据处理    4-5 周    Python、PowerShell、Bash、SQL、正则
   │
阶段 3  安全基础与攻击框架 5-6 周   安全概念、密码学、攻击总览、漏洞管理、Web 漏洞、Webshell、ATT&CK/Kill Chain 概览
   │
阶段 4  主机与流量分析    8-10 周   日志源与规范化、Windows 日志、Sysmon、Linux 审计、EDR、恶意样本、Wireshark、NIDS
   │
阶段 5  蓝队核心能力      6-7 周    SOC、SIEM、告警研判、IR、应急、情报、狩猎、取证
   │
阶段 6  攻防对抗与实战    8-10 周   ATT&CK 深入、红蓝对抗、权限维持、横向移动、靶场、项目
   │
阶段 7  求职冲刺          2-3 周    简历、项目包装、面试题库、模拟面试、投递复盘
```

### 阶段与产出

| 阶段 | 核心目标 | 必须产出 |
|---|---|---|
| 0 认知与准备 | 知道蓝队做什么，环境可用 | 虚拟机环境、学习笔记库、GitHub 账号 |
| 1 基础 | 能独立解释一次网页访问的完整过程 | 网络抓包笔记、Linux/Windows 命令速查 |
| 2 编程 | 能写脚本处理日志与 IOC | 3 个小脚本：日志统计、IOC 提取、批量查询 |
| 3 安全基础与攻击框架 | 理解常见漏洞原理与检测视角，能说出 ATT&CK 战术 | 10 个漏洞的「原理-日志特征-防御」卡片、ATT&CK 战术速查 |
| 4 主机与流量 | 能从主机与流量中发现异常 | Sysmon/Windows 日志分析报告、PCAP 分析报告 |
| 5 蓝队核心 | 能完成一次告警研判与应急演练 | 告警研判报告、应急响应报告各 1 份 |
| 6 攻防与实战 | 能把 TTP 映射到检测 | ATT&CK 检测覆盖表、蓝队靶场通关记录 |
| 7 求职 | 能通过初级蓝队面试 | 一页简历、项目集、面试题库答案 |

## 7. 学习方法

1. **以输出倒逼输入**：每学一个知识点，写一篇 500-1000 字笔记，包含「原理 + 日志特征 + 检测方法 + 防御」。
2. **实验优先**：蓝队是实践岗位。看十遍教程，不如自己抓一次包、查一次日志、做一次应急。
3. **建立知识库**：用 Markdown + Git 管理笔记；每条检测规则注明数据源、字段、误报、验证方法。
4. **围绕 ATT&CK 组织知识**：学攻击手法时问「产生什么日志」「如何检测」「如何缓解」。
5. **复盘靶场**：做完靶场不要只看答案，要写「我漏了什么线索、为什么漏、下次怎么查」。
6. **定期模拟面试**：把面试题当检测清单，发现盲区立即回补。
7. **关注真实事件**：读厂商事件报告与 DFIR 报告，学习攻击链、IOC 与处置过程。
8. **不要陷入工具收集**：工具会用即可，核心是数据源、分析思路与流程。

## 8. 常见误区

| 误区 | 问题 | 正确做法 |
|---|---|---|
| 只学攻击，不学防御 | 面试讲不清检测与处置 | 攻击原理服务于检测，重点写「日志特征」 |
| 只背命令，不懂原理 | 换个环境就不会 | 理解协议、系统机制与日志含义 |
| 沉迷收集工具 | 工具一大堆，一个不精 | 先精通 Wireshark、Sysmon、SIEM 查询、VT |
| 只看视频不动手 | 面试一问就露馅 | 每个模块至少做 1 个实验与 1 份报告 |
| 追求「黑客感」 | 忽视流程、文档、沟通 | 蓝队一半是分析与写作能力 |
| 不看法律边界 | 好心办坏事 | 只做授权范围内的测试与取证 |
| 简历堆砌名词 | 追问即崩 | 每个名词准备一个真实案例 |
| 忽略英语 | 一手资料看不懂 | 每天读 15 分钟英文安全文档 |

## 9. 法律、道德与授权

> 本路线所有技术内容仅用于**授权范围内的防御、检测、应急与教学**。

- 未经授权扫描、入侵、获取数据、破坏系统均可能违反《中华人民共和国网络安全法》《数据安全法》《个人信息保护法》《刑法》相关规定。
- 渗透测试、红蓝对抗、漏洞复现必须在**书面授权**和**明确范围**内进行。
- 应急响应中注意证据保全与个人信息最小化原则，不随意传播样本、日志与用户数据。
- 公开平台（如 VirusTotal）上传样本前，确认不包含企业敏感信息与个人信息。
- 反制与溯源存在法律风险，企业场景应通过法务与执法机关处理，个人不要「反黑」。

## 11. 进阶方向（5 星，实习后再学）

以下方向难度高、通常需要 2-5 年积累，不属于「0 基础到实习」的必学范围，但可作为长期目标：

| 方向 | 内容 | 前置 |
|---|---|---|
| 逆向工程 | 汇编、调试器、脱壳、协议逆向 | C/C++、操作系统、汇编 |
| 漏洞利用开发 | 内存破坏、堆栈/堆利用、缓解绕过 | 逆向、编译原理、二进制 |
| 内核与驱动安全 | Windows/Linux 内核、Rootkit、BYOVD | 操作系统内核、驱动开发 |
| 高级 DFIR | 内存取证、时间线、反取证对抗 | 取证基础、文件系统 |
| 检测工程 | 大规模规则、数据管道、测试框架 | SIEM、编程、ATT&CK |
| 云原生安全 | K8s 安全、容器逃逸、云 IAM | Linux、网络、云基础 |
| 威胁情报/归因 | APT 跟踪、基础设施分析、归因 | 情报、地理/语言/行业知识 |
| 紫队/攻击模拟 | 自动化对抗、检测验证 | ATT&CK、红队基础 |
| OT/ICS 安全 | 工控协议、PLC、网络分区、IEC 62443 | 网络、工控基础 |
| AI/LLM 安全 | 提示注入、数据泄露、模型供应链、AI 辅助防御 | 应用安全、机器学习基础 |

> 先把实习所需的基础打牢，再选择 1-2 个方向深耕。不要因为「5 星很酷」而跳过基础。

```text
先懂系统与网络，再学编程与日志；先学攻击原理，再做检测防御；
先练主机与流量，再上 SIEM 与应急；最后用靶场和项目把知识串起来。
```
