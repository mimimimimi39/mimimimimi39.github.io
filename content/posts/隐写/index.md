隐写大概是 CTF 里最容易让人产生「我学会了」错觉的方向：看两篇 writeup，装几个工具，跑几条命令，flag 就出来了。也正因为如此，很多人一头扎进冷门工具和偏门技巧里，学了很久，比赛里却几乎用不上。

先说我的结论：**隐写要学，但不值得深挖。** 了解常见思路、能独立做简单题、遇到没见过的题知道去哪查，就够了。Misc 的训练时间，大头更应该留给取证和流量分析。下面是我的理由，以及一份我认为性价比足够高的学习路线。

## 一、为什么说隐写是新手陷阱

### 1. 出现频率在下降，且题目越发阴间

近几年的比赛里，Misc 的重心明显偏向取证、流量，甚至是ai安全，纯隐写题几乎没有了。不过新生赛、部分线上赛仍然喜欢出隐写，因为出题成本低、区分度直观。所以不能完全不会，但也没必要为它准备一整个武器库。

### 2. 投入产出比不稳定

隐写的技巧非常分散：图片、音频、文档、压缩包、文本，每类都有自己的工具链。你花一周学的某个冷门方法，可能一年都遇不到一次；而同样的时间拿去学流量分析，几乎每场 CTF 都能用上。

### 3. 方法不可穷举

隐写的出题空间几乎是无限的：改文件头、追加数据、LSB、频谱、零宽字符、伪加密、CRC 碰撞……你不可能学完所有方法。更现实的做法是掌握做题逻辑，而不是死记做法。

### 4. 学习容易变成收藏工具

新手最常见的状态是：收藏了十几个 stego 工具，每个都只会跑默认参数。遇到题还是不知道从哪下手。工具不是知识，排查思路才是。

### 5. 门槛低，队友能补位

简单隐写的学习成本极低，队里其他方向的人临时补一补也能做。相比之下，取证和流量更需要长期积累，也更难被替代。

### 6. 隐写真正的价值

隐写真正训练的是**对文件格式的直觉**：知道 PNG 的块结构、JPEG 的 EXIF、ZIP 的目录区、音频的采样点意味着什么。这种直觉在取证、逆向、甚至 Web 上传题里都可能用得上。但并不值得深挖

## 二、隐写真正值得学的东西

按重要性排序，我认为是：

1. **文件格式与结构**：文件头、块、长度字段、CRC、压缩流、元数据

2. **编码与进制**：Base64、Hex、URL 编码、Unicode、摩斯、二进制位操作

3.  **工具的使用**：stegsolve，archpr，010editor，随波逐流等隐写相关工具

4.  **命令行基本功**：`file`、`strings`、`xxd`、`binwalk`、`exiftool` 的组合使用

5. **一点点信号处理**：频谱图、DTMF、SSTV 这些听上去吓人，其实套路固定

5. **脚本化能力**：会用 Python 读写字节、改图片、爆破 LSB

至于各种冷门工具的特殊参数，需要时查文档就行。

## 三、分阶段学习路线

下面的时间只是参考，重点是每一阶段都要有「掌握标准」，达不到就别急着往下一阶段跑。

### 阶段 0：工具与基本功（1~2 天）

先学会对任何附件做一遍基础体检：

```bash
file target          # 真实文件类型
exiftool target      # 元数据、注释、GPS、软件信息
strings -n 6 target  # 可打印字符串
binwalk target       # 识别嵌入的文件、压缩流
xxd target | head    # 看文件头，确认魔数
```

再补一点常识：

- 常见文件头：PNG `89 50 4E 47`、JPEG `FF D8 FF`、ZIP `50 4B 03 04`、PDF `%PDF`
- `file` 说是 PNG，不代表它只能是 PNG；`binwalk` 能看出后面还粘了什么
- 十六进制编辑器至少会用一种，比如 `010 Editor`、`winhex`

**掌握标准**：拿到任意附件，能在 5 分钟内判断它的真实类型、有没有附加数据、元数据里有没有可疑信息。

### 阶段 1：图片隐写（3~5 天）

图片是隐写题的主战场，优先掌握 PNG 和 JPEG。

**PNG**

- 块结构：`IHDR`、`IDAT`、`IEND`，以及 `tEXt`、`zTXt` 这些可以藏文本的块
- 宽高被改：图片显示异常，需要修复 IHDR 并重算 CRC
- 追加数据：`IEND` 之后还跟着内容，`binwalk` 或 `foremost` 可以分离
- 多图层、调色板、透明通道：用 StegSolve 逐通道看

**JPEG**

- EXIF、注释段、缩略图
- 文件尾追加数据
- 量化表、DCT 系数类隐写：新手知道有这个方向即可，遇到再查

**LSB 与通道**

- LSB（最低有效位）是最经典的图片隐写，用 `zsteg`、StegSolve、StegOveritas 都能看
- 依次检查 R/G/B/A 通道、位平面、反色、异或

**工具**

`binwalk`、`foremost`、`pngcheck`、`zsteg`、`StegSolve`、`StegOveritas`、`CyberChef`、`Pillow`

**掌握标准**：能独立处理「图片打不开」「图片后面有东西」「LSB 藏文本」「二维码被裁切/反色」这几类题。

### 阶段 2：音频隐写（2~3 天）

音频题的套路比图片更固定：

- **频谱图**：Audacity 切到 Spectrogram，看有没有画出来的文字或图形
- **DTMF**：电话按键音，用 `multimon-ng` 或 Audacity 分析
- **摩斯电码**：长短音、滴答声
- **SSTV**：慢扫描电视，用 QSSTV / RX-SSTV 解码成图片
- **WAV LSB**：采样点最低位藏数据，用 Python 或 `stegolsb` 处理
- **波形/声道差异**：左右声道相减、倒放、变速

**掌握标准**：听到一段音频，知道先看频谱，再判断是 DTMF、摩斯还是 SSTV。

### 阶段 3：文档与压缩包（2~3 天）

**压缩包**

- 伪加密：ZIP 的加密标志位被改，`7z` 报密码错误但数据没加密
- 已知明文攻击：用 `bkcrack` 还原密钥
- CRC 碰撞：文件内容被改但 CRC 被保留，可以用脚本爆破
- 隐藏文件、注释、额外字段：`unzip -l`、`zipinfo -v`、十六进制查看

**PDF**

- 流对象、压缩流（`/FlateDecode`）、隐藏对象
- 工具：`pdf-parser`、`qpdf --qdf`、`pdftotext`、`mutool`

**Office**

- `docx` / `xlsx` / `pptx` 本质是 ZIP，先解压看 `word/`、`xl/` 里的 XML
- 隐藏文字（`w:vanish`）、批注、修订记录、宏
- 工具：`olevba`、`oledump`、`unzip`

**掌握标准**：能判断压缩包是伪加密还是真加密，能从 PDF/Office 文件里把隐藏文本和对象挖出来。

### 阶段 4：文本与其他（1~2 天）

- 零宽字符：`U+200B`、`U+200C`、`U+200D`、`U+FEFF`
- 空白字符：行尾空格、Tab 混排
- Unicode 同形字、不可见字符
- 编码套娃：Base64 → Hex → 摩斯 → 反转
- 二维码：损坏、反色、透视、拼接，工具 `zbarimg`、`QRazyBox`

**掌握标准**：看到「复制出来是空的」「文本看起来一样但比较不相等」这类题，能立刻想到不可见字符。

### 阶段 5：和取证、流量接轨

到这一步，隐写题会自然过渡到取证：

- 内存镜像、磁盘镜像里的隐藏文件
- 流量包中通过 HTTP、DNS、ICMP 外传的数据
- 图片/文档在流量中的还原

这也是我建议尽早把重心移过去的原因：这些技能在比赛里出现得更稳定，也更有迁移价值。

## 四、常见题型速查表

| 类型 | 典型特征 | 首选工具 | 第一反应 |
| --- | --- | --- | --- |
| 文件头损坏 | 打不开、格式识别错误 | `file`、`xxd`、`010 Editor` | 对比正常文件头修魔数 |
| 追加数据 | 图片/文档正常但体积异常 | `binwalk`、`foremost` | 分离尾部数据 |
| PNG 宽高被改 | 显示不全、CRC 报错 | `pngcheck`、Python | 修 IHDR 并重算 CRC |
| LSB | 像素噪声、通道异常 | `zsteg`、StegSolve | 逐通道、逐位平面 |
| EXIF/注释 | 元数据异常 | `exiftool`、`strings` | 读注释和软件字段 |
| 音频频谱 | 声音正常但波形可疑 | Audacity | 切频谱图 |
| DTMF/SSTV | 电话音、机器音 | `multimon-ng`、QSSTV | 解码成数字或图片 |
| 压缩包伪加密 | `7z` 要密码但数据可疑 | `随波逐流`、`010 Editor` | 看加密标志位 |
| PDF 隐藏对象 | 页面内容正常但体积大 | `pdf-parser`、`qpdf` | 列对象、解压流 |
| 零宽字符 | 文本复制出来是空的 | Python、在线工具 | 提取不可见码点 |
| 编码套娃 | 一串 Base64/Hex | CyberChef | 逐层解码、看规律 |

## 五、工具清单

不用全装，按需取用。Kali 自带大部分，Windows 建议用随波逐流，内置很多功能

**基础排查**

`file`、`strings`、`xxd` / `hexdump`、`binwalk`、`foremost`、`exiftool`

**图片**

`pngcheck`、`zsteg`、`StegSolve`、`StegOveritas`、`Pillow`、ImageMagick

**音频**

Audacity、Sonic Visualiser、`multimon-ng`、QSSTV / RX-SSTV

**文档与压缩包**

`7z`、`zipinfo`、`bkcrack`、`pdf-parser`、`qpdf`、`olevba`、`oledump`

**通用**

CyberChef、Aperisolve（在线聚合）、Python

在线工具很方便，但涉及比赛附件时注意不要上传敏感文件；自己能本地跑的最好本地跑。

## 七、练哪里

- **ctfshow**：misc​入门分区全是隐写，非常适合新手入门，但也是把我拖入隐写大坑的元凶之一
- **CTFHub**：技能树里有专门的隐写分类，适合按知识点刷（技能树题目多已过期）
- **BUUCTF**：Misc 新手区题量大，适合找手感
- **攻防世界**：Misc 新手区，题目偏经典（现多数题目转收费）
- **NSSCTF**：题源杂，可以练排查能力
- **MoeCTF / Hackergame**：新生赛和趣味赛，隐写题质量不错


- 练习方法比题量重要：
- 每类先做 5 道简单题，做不出来就看 writeup，然后**关掉 writeup 重做一遍**
- 建立自己的题型笔记，记录「看到什么特征 → 用什么工具」
- 不要追求做完，追求同一类题能独立复现



## 结语

隐写不难，难的是知道什么时候停。它适合用来建立对文件格式的直觉，也适合在新生赛里快速拿分，但不适合当成 Misc 的主线。

我的建议是：花一到两周把常见套路过一遍，能独立做简单题，然后就去做取证和流量。等比赛里真遇到隐写题，场上基本也很难有人能做出来，等你熟练掌握隐写常用解法后就可以停下了
