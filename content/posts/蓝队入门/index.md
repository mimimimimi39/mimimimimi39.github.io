蓝队不是「只会看告警」，而是负责防御、检测、响应、溯源和持续改进。这条路线面向零基础、转行、在校生和初级安全从业者，目标是建立起可以实习的蓝队能力栈。

## 先说结论

- 目标岗位：SOC 初级分析师、安全运营实习生、应急响应助理、安全服务工程师助理
- 总投入：约 600–800 小时（含实验），标准节奏 9–12 个月，每周 15–20 小时
- 加速节奏 5–6 个月，每周 30–35 小时；只有 3 个月时走「面试入门路线」，但不等于完整实习能力
- 主线：**看得见 → 拦得住 → 查得清 → 恢复得快 → 防得久**
- 蓝队必须理解攻击者视角，但学习攻击原理的目的是检测和防御

## 一、蓝队有哪些岗位

| 岗位 | 核心工作 | 入门难度 |
| --- | --- | --- |
| SOC 分析师 L1 | 盯告警、初判、工单、升级 | 低 |
| SOC 分析师 L2 | 深入研判、关联分析、处置建议 | 中 |
| 应急响应工程师 | 入侵排查、遏制、清除、取证 | 中高 |
| 安全运营工程师 | SIEM 规则、日志接入、告警调优、SOAR | 中 |
| 威胁情报分析师 | IOC/TTP 生产与落地、情报运营 | 中高 |
| 威胁狩猎工程师 | 假设驱动狩猎、检测工程 | 高 |
| 安全服务工程师 | 基线核查、风险评估、等保、驻场 | 低中 |
| 安全研发工程师 | 检测平台、自动化、EDR/SIEM 开发 | 高 |

## 二、可实习蓝队的能力模型

| 能力域 | 实习要求 |
| --- | --- |
| 网络与协议 | 看懂 TCP/IP、HTTP/DNS/TLS，能用 Wireshark 过滤 |
| 操作系统 | Linux 常用命令、Windows 账号/服务/注册表/事件日志 |
| 编程与数据 | Python 读写日志/调 API，PowerShell/Bash 排查，SQL 查日志 |
| 安全基础 | 常见 Web 漏洞、密码学常识、漏洞管理 |
| 日志与检测 | 常见日志源、关键事件 ID、告警研判流程 |
| 应急响应 | 准备-检测-遏制-根除-恢复-复盘 |
| 流量分析 | 识别扫描、爆破、Webshell、C2 流量特征 |
| 威胁框架 | 用 ATT&CK 描述攻击行为并映射检测 |
| 工具 | SIEM、EDR、Wireshark、Sysmon、VT、沙箱 |
| 沟通与文档 | 工单、事件报告、复盘报告 |
| 法律合规 | 授权边界、证据保全、个人信息保护 |

## 三、8 个学习阶段

```text
阶段 0  认知与准备        1-2 周    岗位认知、学习方法、实验环境、法律边界
阶段 1  计算机与网络基础  6-8 周    计算机组成、Linux、Windows、TCP/IP、HTTP、DNS、数据库
阶段 2  编程与数据处理    4-5 周    Python、PowerShell、Bash、SQL、正则
阶段 3  安全基础与攻击框架 5-6 周   安全概念、密码学、攻击总览、漏洞管理、Web 漏洞、ATT&CK 概览
阶段 4  主机与流量分析    8-10 周   日志源、Windows 日志、Sysmon、Linux 审计、EDR、Wireshark、NIDS
阶段 5  蓝队核心能力      6-7 周    SOC、SIEM、告警研判、IR、应急、情报、狩猎、取证
阶段 6  攻防对抗与实战    8-10 周   ATT&CK 深入、红蓝对抗、权限维持、横向移动、靶场、项目
阶段 7  求职冲刺          2-3 周    简历、项目包装、面试题库、模拟面试、投递复盘
```

| 阶段 | 核心目标 | 必须产出 |
| --- | --- | --- |
| 0 认知与准备 | 知道蓝队做什么，环境可用 | 虚拟机环境、笔记库、GitHub 账号 |
| 1 基础 | 能解释一次网页访问的完整过程 | 抓包笔记、Linux/Windows 命令速查 |
| 2 编程 | 能写脚本处理日志与 IOC | 日志统计、IOC 提取、批量查询脚本 |
| 3 安全基础 | 理解漏洞原理与检测视角 | 10 个漏洞「原理-日志特征-防御」卡片 |
| 4 主机与流量 | 能从主机和流量中发现异常 | Sysmon/Windows 日志报告、PCAP 分析报告 |
| 5 蓝队核心 | 能完成一次告警研判与应急演练 | 告警研判报告、应急响应报告 |
| 6 攻防与实战 | 能把 TTP 映射到检测 | ATT&CK 检测覆盖表、靶场通关记录 |
| 7 求职 | 能通过初级蓝队面试 | 一页简历、项目集、面试题库答案 |

## 四、模块清单

### 01 学习指南

岗位与能力模型、学习路线与阶段规划、实验环境搭建、认证与职业发展。

### 02 计算机与网络基础

计算机组成、Linux、Windows、计算机网络、HTTP、HTTPS/TLS、DNS、数据库。

### 03 编程与工具

Python、PowerShell、Bash、SQL 与日志查询、正则表达式。

### 04 安全基础知识

安全概念、密码学、攻击类型总览、漏洞管理与 CVE、OWASP Top 10、SQL 注入、XSS/CSRF、文件上传与命令注入、SSRF/XXE、反序列化、Webshell、云安全与容器。

### 05 蓝队核心能力

SOC 与安全运营、SIEM 与日志平台、日志分析与日志源、告警研判、IR、应急响应、威胁情报、威胁狩猎、溯源与取证。

### 06 主机与终端安全

Windows 安全机制、Windows 日志分析、Sysmon、Linux 日志与审计、EDR/HIDS、恶意软件、样本分析、安全基线加固。

### 07 网络流量分析

Wireshark 抓包、流量异常检测、NIDS（Suricata/Snort）、防火墙/WAF/代理。

### 08 威胁框架与攻防对抗

MITRE ATT&CK、网络杀伤链、红蓝对抗、常见入侵手法、权限维持、横向移动、内存马与无文件攻击、反取证。

### 09 实战与靶场

在线靶场（TryHackMe、LetsDefend、BTLO、CyberDefenders 等）、CTF 与蓝队比赛、综合实战项目。

### 10 求职与面试

简历与面试准备、蓝队面试题库。

### 11 资源汇总

网站、博客、书籍、课程、工具、社区和标准。

## 五、三条时间路线

### 标准节奏（9-12 个月）

每周 15-20 小时：

1. 阶段 0 + 1：认知、环境、计算机与网络基础
2. 阶段 2：Python / PowerShell / Bash / SQL / 正则
3. 阶段 3：安全基础与 Web 漏洞
4. 阶段 4：日志、主机、Sysmon、EDR、Wireshark
5. 阶段 5：SOC、SIEM、告警、IR、应急
6. 阶段 6：ATT&CK、攻防对抗、靶场、项目
7. 阶段 7：简历、面试、投递

### 加速节奏（5-6 个月）

每周 30-35 小时，适合有 IT 基础、能全职投入的人：

- 基础只学蓝队高频部分，边学边做实验
- Python 以「能处理日志」为目标，不追求算法
- Web 漏洞重点掌握原理、日志特征和防御
- 阶段 4/5 直接结合靶场案例
- 最后留 2-3 周做简历和面试

### 3 个月面试入门

```text
实验环境与法律边界 → 网络 → Linux/Windows
→ 日志与 Windows 日志 → Wireshark
→ SIEM / 告警 → IR / 应急基础
→ ATT&CK 基础 → 靶场 → 简历
```

这条路线能让你去面试初级岗位，但不承诺独立应急能力。长期竞争力仍然取决于编程、流量分析、威胁狩猎和项目深度。

## 六、阶段验收标准

### 阶段 1

- 能画出一次 HTTPS 访问从 DNS 到页面渲染的完整链路
- 能在 Linux 上排查用户、权限、服务、日志、计划任务
- 能在 Windows 上找到账号、服务、启动项、计划任务、事件日志
- 能用 Wireshark 过滤 HTTP 请求并导出对象

### 阶段 2

- 用 Python 读取日志、统计 Top IP、提取 URL 和 IP
- 用 PowerShell 查询进程、服务、计划任务、登录日志
- 用 Bash 管道完成 TopN、去重、时间过滤
- 用 SQL 完成多表关联与聚合
- 用正则提取 IP、域名、URL、Hash、邮箱

### 阶段 3

- 能解释 OWASP Top 10 每一类的原理
- 能说出 SQLi/XSS/文件上传/命令注入的日志与流量特征
- 能解释 CVE、CVSS、CWE、EPSS、KEV 的区别
- 能识别一句话木马、冰蝎/哥斯拉流量的基本特征
- 能说出 ATT&CK 的 14 个战术与 Kill Chain 七阶段

### 阶段 4

- 能列出主机/网络/安全/应用/云的主要日志源
- 能从 Windows 安全日志还原一次登录与进程执行
- 能配置 Sysmon 并用事件 ID 1/3/11/22 做排查
- 能用 auditd 与 auth.log 发现 SSH 爆破与提权
- 能用 Wireshark 识别扫描、爆破、Webshell、C2 流量

### 阶段 5

- 能说清 SOC L1/L2/L3 的职责边界
- 能独立完成一条告警的研判并写出结论
- 能按 NIST/SANS 流程处理一次模拟事件
- 能写一份包含时间线的应急响应报告
- 能解释 IOC、IOA、TTP 与金字塔模型

### 阶段 6

- 能把一个攻击案例映射到 ATT&CK 战术与技术
- 能针对 10 个常见 TTP 写出检测思路
- 能完成至少 10 个蓝队靶场案例
- 能独立完成一个家庭 SOC 或日志分析项目
- 能在 GitHub 上展示 1-2 个讲得清楚的项目

## 七、练哪里

- **TryHackMe**：SOC、蓝队、Windows 基础路径
- **LetsDefend**：偏向 SOC 告警研判
- **BTLO**：Blue Team Labs Online，案例练习
- **CyberDefenders**：真实事件和取证练习
- **Wazuh / ELK / Security Onion**：搭一个自己的家庭 SOC
- **Sysmon + Velociraptor**：主机日志与排查
- **CTF 与蓝队比赛**：应急响应赛、护网、取证赛

项目建议：

- 家庭 SOC：日志采集 → 解析 → 告警 → 研判报告
- Windows 入侵排查：登录日志、进程、服务、计划任务、启动项
- 流量分析：扫描、爆破、Webshell、C2 各做一个案例
- 样本分析：静态信息、沙箱行为、IOC、YARA 规则

## 八、常见坑

- 只看视频不动手，实验环境一直没搭起来
- 把蓝队学成「背工具」，不会从日志还原行为
- 只学攻击不学检测，或者只学检测不理解攻击
- 日志字段不熟，告警来了不知道看什么
- 不做时间线，事件定性全靠猜
- 简历写「精通」，面试一问就露馅
- 忽略法律边界和证据保全
- 没有项目，只有课程证书

## 九、最后

蓝队路线看起来很长，但它的结构很稳定：**基础 → 编程 → 安全 → 日志与流量 → 核心运营 → 实战 → 求职**。按阶段走，每个阶段留下一个可展示的产出，比收藏一堆课程更有用。
